# JANUS MAD-LAB

Status: **EXPERIMENTAL / NOT THEOREM**  
Seal: **IANUS VIAS SERVAT.**

This directory is a deliberately isolated sandbox for speculative, adversarial,
reverse-order, numerological, physical-metaphor, unusual-search, and otherwise
high-risk research ideas that must not contaminate the proof-carrying theorem
path.

## One-way membrane

The MAD-LAB may read frozen theorem-side artifacts as test instruments, but the
theorem runtime must never import MAD-LAB code. Nothing in this directory may
be cited as a theorem merely because it passes a finite experiment or CI run.
Promotion requires a separate proof artifact outside this directory, exact
scope, independent replay, claim-ceiling audit, and explicit reviewed promotion.

## M2R pre-action jump gate

`m2r_jump_counter.py` computes the frozen theorem-side raw upper bound before an
action and compares it with `N^2`.

- `LAND`: cap-safe under the supplied exact bound.
- `VETO`: primary action exceeds cap.
- `JUMP`: another already supplied cap-safe action is selected canonically.
- `OPEN`: no supplied safe action exists; the obstruction is preserved.

M2R has veto power, not truth power. A jump is action-level and never means
skipping a failed N for a theorem claim.

## M2R Surgeon self-repair

`m2r_self_repair.py` adds a proof-gated repair stage after a veto. It may tighten
the bound only through exact providers that were proved *before* the current
run. The current imported chain contains global raw accounting, incidence
surplus, and the proved N58 local rescues through 23x27.

If those exact providers close the cap, the action receives `REPAIRED_LAND`.
If they do not, M2R emits a concrete proof obligation, performs logical rollback,
and returns `OPEN_REPAIR_REQUIRED`.

A new lemma imagined during the same run may be recorded as a future candidate,
but **cannot be used in that run**. This is the anti-self-deception wall.

## Spider methodology gate

`SPIDER_METHOD_IMPORT.json` and `spider_method_gate.py` import only methodological
controls from the user-supplied TOPA-SPIDER dossier:

- freeze scope/action order/falsification rule before evaluation;
- preserve negative and disconfirming results;
- stop/abandon an action when checks do not justify continuation;
- separate discovery primes from later confirmation of any pattern.

The dossier's tachyon, precognition and physical-retrocausality material is not
promoted as established physics or theorem machinery.

## Active ascending-prime stress lane

`prime_stress_ascending.py` is now the active stress route. It runs only prime
numbers in ascending order, by default:

`2, 3, 5, 7, 11, ... , 929, 937`.

At every prime it freezes the same current discovery scope:
`N7_HARD_ROOT_BOUNDARY_FIRST_OPEN_SCAN`. Within that scope it scans canonical
`m -> d -> p` order, applies M2R + M2R Surgeon, records the first unresolved
obstruction, rolls that action back, and continues to the next prime instead of
stopping the whole stress run.

A `NO_OPEN_IN_SCANNED_LANE` result means only that this frozen n=7 root lane had
no unresolved action under the current exact repair chain. It does **not** prove
that N, any composite gap, unbounded totality, SAT in P, or P=NP.

The older descending `937 -> ...` prime scheduler is retained as a historical
alternate experiment but is no longer the active route.
