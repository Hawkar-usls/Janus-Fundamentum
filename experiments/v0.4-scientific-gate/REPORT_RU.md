# JANUS P–N Junction v0.4 — официальный синтетический scientific gate

## Решение

**Scientific gate: TRUE**

- Seed закрытого holdout: `440232`
- Основной бюджет: `28n` итераций для обоих методов
- SAT-точек: 7
- Испытаний на точку: 50
- Всего SAT-испытаний для Gladius: 350
- Сертифицированных UNSAT-испытаний: 80
- Барьерных packet-gate испытаний: 60
- Устройства в этом этапе не использовались

Граница вывода: это конечный синтетический gate, разрешающий перейти к подготовке аппаратного теста. Это не доказательство `P = NP`, не доказательство полиномиального worst-case и не физическое доказательство эквивалентности классов сложности полупроводниковому p–n-переходу.

## Замороженный кандидат

Кандидат `Gladius v0.4 gate2_5` использует:

1. заряд устойчиво неудовлетворённых клауз;
2. вычислительную глубину локальной обеднённой области;
3. ограниченные одиночные переходы через неглубокий барьер;
4. только проверяемые пакетные переходы в специальном barrier-gate;
5. пять последовательных нуклеаций поля внутри неизменного общего бюджета `28n`;
6. детерминированные seed через SHA-256;
7. явный учёт committed flips и probe operations;
8. ранний `PROVEN_NO_RECOMBINATION` только при найденном формальном свидетеле противоречия.

Разбиение бюджета пяти нуклеаций: `42% / 22% / 16% / 11% / 9%`.

## Зафиксированные критерии

Gate считался TRUE только при одновременном выполнении всех условий:

- Gladius решает 100% SAT-испытаний на каждой точке;
- solve-rate Gladius нигде не ниже Anchor;
- Gladius выигрывает или сравнивается по медиане переходов минимум на 4 из 7 точек;
- нет ни одного ложного SAT на сертифицированных UNSAT;
- UNSAT-контроли получают состояние `PROVEN_NO_RECOMBINATION`;
- специальная локальная ловушка проходится проверенным пакетным переходом без одиночного ухудшающего хода;
- повтор одного и того же входа и seed даёт идентичный результат;
- суммарная нормализованная работа Gladius не превышает Anchor более чем в 1.5 раза.

После запуска критерии не менялись.

## Цена результата

- средняя работа Anchor: `102.6114`;
- средние committed flips Gladius: `82.7371`;
- средние probe operations Gladius: `22.2229`;
- общая нормализованная работа Gladius: `104.9600`;
