## The structural theorem

Let `M` be the nonempty set of models of a Horn formula `H` over variables
`x1,...,xn`.

Horn model sets are closed under coordinatewise conjunction, so `(M, AND)` is a
finite meet semilattice.

For every variable define the coordinate function

```text
chi_i : M -> GF(2)
chi_i(a) = a_i.
```

Because multiplication in `GF(2)` is Boolean conjunction,

```text
chi_i(a AND b) = chi_i(a) * chi_i(b).
```

Thus every nonzero coordinate function is a multiplicative semilattice character.
The constant-one function is another character.

### Independence lemma

Distinct nonzero multiplicative characters of a semigroup into a field are
linearly independent.

For completeness, C037.2 includes the elementary minimal-relation proof. Suppose

```text
sum_i c_i chi_i = 0
```

is a shortest nontrivial relation. Choose `s` on which `chi_1(s) != chi_m(s)`.
Evaluate the relation at `s AND t` and subtract `chi_m(s)` times the relation at
`t`. The `m`-th term disappears and a shorter relation remains. Its coefficient
of `chi_1` is

```text
c_1 * (chi_1(s) - chi_m(s)) != 0,
```

contradicting minimality.

### Affine-hull corollary

Consider an affine equation valid on every Horn model:

```text
XOR_{i in T} x_i = b.
```

As an identity of functions on `M`, this is a linear relation among the coordinate
characters and the constant-one character.

Group variables by their coordinate functions:

- the zero character means `H |= x_i = 0`;
- the constant-one character means `H |= x_i = 1`;
- equal nonconstant characters mean `H |= x_i = x_j`;
- all remaining distinct nonzero characters are linearly independent.

Therefore the equation is valid exactly when:

1. every nonconstant equality class occurs an even number of times; and
2. `b` is the parity of the fixed-one variables occurring in the row.

Hence every Horn-entailable affine row is an XOR combination of:

```text
x_i = 0
x_i = 1
x_i XOR x_j = 0.
```

This is a characterization of the affine hull of a Horn relation, not a new width
parameter.

## Constructive basis discovery

C037.2 discovers the complete basis using only native Horn procedures.

### Forced literals

For every variable `x`, solve both restricted Horn formulas:

```text
H AND x=0
H AND x=1.
```

If one is UNSAT, the opposite literal is forced and the least-model conflict trace
is retained.

### Equality classes

For every pair of nonconstant shared variables `x,y`, test:

```text
H |= (not x OR y)
H |= (x OR not y).
```

Each test is a Horn query with falsifying units. Equal variables are compressed to
a deterministic union-find spanning forest. Discovery checks all pairs, but the
emitted proof basis contains at most `|S|-1` equality rows.

### Higher-arity rows

The forced-literal and equality rows are reduced to an augmented `GF(2)` row basis.
Every target affine row is then either:

- reduced to zero, with a provenance bitset identifying its basis combination; or
- left with a nonzero residual, proving that it is not a Horn consequence by the
  structural theorem.

No enumeration of `2^(arity-1)` falsifying assignments is performed.

## Constructive separator recovery

A nonzero residual establishes existence of a Horn model violating the affine row,
but C037.2 also constructs one.

Maintain a prefix assignment `U`. For the next variable, test the two Horn
restrictions `U union {x=0}` and `U union {x=1}` with the complete affine-hull
entailment procedure. Since the parent does not entail the row, at least one child
also fails to entail it. Choose the first such child deterministically.

After all variables are fixed, the resulting assignment:

```text
satisfies H
violates the selected affine row.
```

This is polynomial self-reduction using a proved polynomial decision procedure,
not an arbitrary SAT oracle.
