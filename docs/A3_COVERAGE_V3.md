В исходной базе r=3 представлен 30 входами, но все имеют (2,2,2), без middle copies. После дополнения r=3 представлен 120 входами, 90 из них со средней копией. Это не расширяет покрытие до k>3, d>2 или r>3.

Геометрический срез «все классы ненулевые и строго собственные» содержит 7/9/5 геометрий при k=1/2/3, всего 277 базовых inputs. Для r=3 это 5 базовых и 15 дополнительных inputs; остальные включают нулевое или полное подпространство. Этот срез не объявляется мерой сложности.

Группы saturation фиксируют точные U, IDs классов и весь вектор min(a,2), а не только количества s,r. Получено 382 группы. В базе 278 групп имеют разные исходные multiplicity profiles, 1439 unordered pairs и 725 нетривиальных сравнений a→cap(a). После дополнения — 308 нетривиальных групп, 1619 pairs, 815 нетривиальных a→cap(a). Сравнивать нужно independently computed full-word optimum для каждой пары и direct pathwise widths; одних совпавших счётчиков недостаточно.

Файлы inputs содержат только raw задачи, без ответов. Каждая строка — canonical JSON и конечный LF. Input hash относится к bytes строки без LF. Index отдельно хранит cohort и saturation group. Полный SHA-256 файла учитывает LF каждой строки.
