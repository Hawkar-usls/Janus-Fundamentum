## Three distinct, non-interchangeable meanings of consistency

1. BOOLEAN MODEL: A proposed complete assignment x is accepted as SAT iff EVERY original SAT clause is satisfied; for Exact-One exactly one literal per row must be true. Independently confirm with janus_ufr_001.verify_model, preserving repeated literal multiplicity.
2. TOY STATE FIXED POINT: x = T(x) on a bounded finite deterministic mapping. Identity may have many stable fixed points; a two-state swap has none. Neither demonstrates real physical time travel nor certifies SAT UNSAT.
3. TRUST DAG: PENROSE-002/003 strictly prohibit a FINAL_GATE -> UFR_PRODUCE dependency. Candidate prediction is generated by forward-in-time code; a hypothetical feedback constraint is never permitted to rewrite the certificate issuer.

## Concrete algorithm

experiments/direct/janus_novikov_001.py:
- Start with the same fallible present-input literal-vote proposal as TACHYON-001.
- Count E(x), the exact number of unsatisfied original clauses.
- Test every Hamming-distance-one neighbor and move to the lowest-energy neighbor ONLY when E strictly decreases; deterministic ties by distance to original suggestion, then variable index.
- Each accepted step reduces integer E by at least 1. Thus the number of steps is no greater than the number of clauses and the trace cannot contain a nontrivial cycle.
- Accept a proposal only when E=0 AND independent verifier agrees. Otherwise record LOCAL_MINIMUM_NOT_UNSAT, never an UNSAT proof.
- Independently rebuild the complete proposed sequence to reject forged status, energy, transition, or tie-break.
- Search remaining alternatives with the complete bounded SAT/Exact-One DPLL, including independent full 2^n enumeration for every UNSAT result at n<=10. The original C023 certificate verifier remains separate.

A local minimum can exist when SAT remains satisfiable. Strictly decreasing energy is a termination guarantee, not a SAT complexity theorem.
