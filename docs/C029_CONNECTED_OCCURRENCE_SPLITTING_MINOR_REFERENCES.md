# C029 primary references

- Neil Robertson and P. D. Seymour, *Graph minors. III. Planar tree-width*, Journal of Combinatorial Theory, Series B 36 (1984), DOI `10.1016/0095-8956(84)90013-3`.
- Marko Samer and Stefan Szeider, *A Fixed-Parameter Algorithm for #SAT with Parameter Incidence Treewidth*, arXiv `cs/0610174`.

The first supplies the graph-minor/treewidth framework. The second supplies the algorithmic role of incidence treewidth for SAT-style dynamic programming.
