# C020 addendum — Policy-0A lifting bridge

## Status

`FORMALIZING / ASYMPTOTIC ROUTE IDENTIFIED / SIMULATION CERTIFICATE MISSING`

The finite masked-Tseitin experiments show representation sensitivity but do not
by themselves prove superpolynomial growth. This note identifies a published
lifting theorem that can convert a proof-depth simulation lemma for Policy-0A
into an asymptotic lower bound.

## Primary external theorem

D. Itsykson, V. Podolskii, and A. Shekhovtsov,
*Resolution Width Lifts to Near-Quadratic-Depth Res(⊕) Size*, ECCC TR26-018,
2026.

The theorem used here states:

> Let `phi` be an unsatisfiable CNF whose resolution refutation width is at
> least `w`, and let `g` be a constant-size 1-stifling gadget. Every
> `Res(⊕)` refutation of `phi o g` of size at most `S` has depth
> `Omega(w^2 / log S)`.

The paper gives `MAJ3` as a 1-stifling example and derives nearly quadratic-depth
size lower bounds for lifted formulas.

This repository does not reproduce that theorem. It treats it as a cited primary
result and isolates the additional lemma needed to apply it to JANUS Policy-0A.

## Why the earlier triangular mask is insufficient

The bijection

```text
x = b XOR (a AND c)
```

is excellent for showing representation dependence, but it is not 1-stifling:
when the free coordinate is `b`, the output always changes with `b`.

Therefore the current lifting theorem does not apply directly to that mask.

## Replacement gadget — MAJ3

Define

```text
MAJ3(a,b,c) = 1 iff a+b+c >= 2.
```

The executable audit checks the 1-stifling definition exactly. For every free
coordinate and target output, fixing the other two coordinates both to the target
forces the majority output independently of the free bit.

It also checks that neither fibre

```text
MAJ3^-1(0)
MAJ3^-1(1)
```

is an affine coset over `GF(2)`.

```bash
python experiments/direct/janus_tear_maj3_stifling_audit.py --self-test
```

## Candidate simulation lemma

### Policy-0A-to-Res(⊕) simulation

Let `F` be an UNSAT formula on `N` variables for which the root affine shortcut
does not fire. Suppose Policy-0A terminates after total charged work `W`.
Then its execution can be converted into a `Res(⊕)` refutation with:

```text
size  O(W)
depth O(N)
```

### Why the lemma should hold

Policy-0A uses only:

1. ordinary resolution additions;
2. restrictions generated by variable branches;
3. unit propagation;
4. exact residual-DAG sharing.

Ordinary clauses and variable queries are special cases of `Res(⊕)` lines and
linear queries.

A standard DPLL branch combination turns two refutations under `x=0` and `x=1`
into a refutation of the parent state. Exact memoization preserves DAG sharing
rather than forcing tree duplication.

Along one source-to-sink path:

- every explicit branch fixes a fresh variable;
- every unit propagation fixes another fresh variable;
- therefore at most `N` variables are fixed in total;
- each residual resolution pass adds only one new proof layer because newly
  generated clauses are not recursively re-indexed within that pass;
- there are at most `N` residual branch levels.

Hence the expected proof depth is linear in `N`, while every charged resolution
addition, branch node, memo node, and terminal conflict contributes only constant
proof-DAG overhead.

## Missing rigor

The simulation lemma is not yet admitted. A complete proof must specify:

1. a provenance record for every generated resolvent;
2. the exact proof object representing unit propagation under restrictions;
3. the branch-combination rule at a parent residual;
4. how one memoized residual proof is reused under multiple incoming paths;
5. a formal depth recurrence proving `D(F) <= cN`;
6. a verifier that checks the emitted proof DAG independently of the solver.

Until these exist, the lifting consequence below is conditional.

## Conditional asymptotic consequence

Take a constant-degree expander family and its odd-charge Tseitin formulas
`T_n`, with resolution width

```text
w(T_n) = Omega(n).
```

Lift every edge variable by `MAJ3`. Constant graph degree and constant gadget
size imply that the lifted CNFs have

```text
N = Theta(n)
```

variables and linear-size constant-width encodings.

The root affine shortcut does not apply: by fixing all other gadget blocks, one
vertex relation restricts to a fibre of `MAJ3`; restrictions of affine relations
are affine, while the audited fibres are non-affine.

Assume Policy-0A had polynomial total work `W = poly(N)` on these formulas. The
simulation lemma would give a `Res(⊕)` proof with

```text
S = poly(N)
D = O(N).
```

The lifting theorem requires

```text
D = Omega(w^2 / log S)
  = Omega(N^2 / log N),
```

contradicting `D=O(N)` for sufficiently large `N`.

Equivalently, substituting `D=O(N)` into the tradeoff yields

```text
S >= 2^Omega(N).
```

Thus, once the simulation lemma is certified, Policy-0A would have an
**exponential asymptotic lower bound** on the MAJ3-lifted expander-Tseitin family.

## Scope boundary

Even after the simulation lemma is proved, the conclusion would be:

> this fully specified Policy-0A cannot be a polynomial-time universal SAT
> policy.

It would not prove `P != NP`, because stronger algorithms and proof systems may
escape the Policy-0A model.

It would, however, replace the finite quadratic-envelope failure by a genuine
infinite lower-bound family and show exactly why the current JANUS Tear policy
cannot solve the general problem.
