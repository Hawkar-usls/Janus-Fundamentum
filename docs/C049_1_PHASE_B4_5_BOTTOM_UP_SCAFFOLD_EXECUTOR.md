# C049.1 Phase B4.5 — universal bottom-up scaffold executor

## Result

Phase B4.5 implements one deterministic bottom-up executor for every node of a
`CATERPILLAR_APPEND_NEW_LEAF` scaffold emitted by B4.2, subject to explicit
capability bounds.  The frozen acceptance instance reaches a root full set.

This is the first certificate in the C049.1 line that passes a computed full
set through more than one internal node.  B4.3 and B4.4 certified isolated node
kernels; B4.5 certifies topology derivation, two exact parent-to-child handoffs,
and one global cumulative ledger.

It does **not** reconstruct a layout and does **not** execute every iterative
compression round.  Consequently neither `FOUND_LAYOUT` nor
`NO_LAYOUT_AT_CAP` is enabled.  The global terminal remains
`OPEN_TRAJECTORY_ENGINE_INCOMPLETE`.

## Frozen B4.2 scaffold

The fixture is generated by the unchanged B4.2 `scaffold()` constructor over
`GF(2)^3`:

- grouped factor blocks: `[(1), (1), (2), (4)]`;
- affine offsets: `[0, 1, 0, 1]`;
- previous order: `[0, 1, 2]`;
- appended leaf: `3`;
- scaffold order: `[0, 1, 2, 3]`;
- candidate-edge widths: `[1, 0, 0]`, within the `3k` cap for `k=1`.

The duplicate linear blocks with different affine offsets are deliberate: the
executor and verifier must preserve factor identity and offset metadata instead
of silently merging equal subspaces.

The derived bottom-up tree contains all two B4.2 spine nodes and an explicit
root-close node:

1. node 4 joins leaves 0 and 1;
2. node 5 joins node 4 with leaf 2;
3. node 6 closes the root by joining node 5 with leaf 3.

Leaf boundaries are `[1]`, `[1]`, `[]`, and `[]`.  Node 4 therefore exercises
nonzero child-boundary transport and shrinks to an empty parent boundary.  Its
computed full set is then consumed by node 5; node 5's output is consumed by
node 6.

## Universal executor contract

For each internal node, the executor:

1. checks exact child output receipts and grouped factor ownership;
2. recomputes child, common-join, and parent boundaries in RREF;
3. enumerates the full Cartesian product of child full-set entries;
4. enumerates every Delannoy lattice path for every pair;
5. records B3 expand, raw join, compactification, shrink, and every failed
   width refinement;
6. deduplicates successful outputs with explicit deletion witnesses;
7. invokes B2 dominance and `up_k`, retaining its removal witnesses;
8. emits a digest-bound output receipt used verbatim by the next node; and
9. continues one global cumulative-work counter without a node-local reset.

The default acceptance capability is 16 internal nodes, 2,000 child pairs per
node, 250,000 refinements per node, and boundary coordinate dimension at most
3.  A preflight excess produces an exact
`OPEN_AT_NODE_CAPACITY` record naming the node, required amount, and cap.  It
never produces `NO_LAYOUT_AT_CAP`.  An empty node full set likewise produces
`OPEN_AT_NODE_EMPTY_FULL_SET`, not a negative layout conclusion.

## Independent verification

The verifier imports the independent B2 and B3 verifier implementations, not
the B4.5 producer.  It reconstructs the B4.2 scaffold and topology, checks every
chunk link and record digest, replays all 164,072 B3 refinements, reconstructs
all B2 closures, verifies both full-set handoffs, and recomputes the global
ledger.

Four digest-repaired semantic attacks must be rejected:

- altered full-set handoff receipt;
- altered RREF transport coordinates;
- merged/altered grouped affine offsets; and
- reset cumulative work at a node boundary.

CI also executes a low-capability control (`max_refinements_per_node=100`) and
verifies the exact open stop at node 4, where 163,824 refinements are required.

## Remaining boundary

B4.5 proves that the implemented B3→B2 kernel can be scheduled across one
complete certified scaffold and can produce a root full set with replayable
provenance.  It does not prove the full iterative-compression algorithm.  The
next gate is `C049.1_B4.6_FULL_ITERATIVE_COMPRESSION_CYCLE`.
