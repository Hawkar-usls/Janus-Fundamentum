## Why admission is forbidden

PR #105 localizes the upstream defect. The implementation had reused the extension-preorder lattice path domain for trajectory join:

```text
extension preorder: (1,0), (0,1), (1,1)
join/interleaving:   (1,0), (0,1)
```

The false zero-root state is generated by the illegal diagonal path

```text
(0,0) -> (1,1)
```

through the scalar table

```text
[[0,1],
 [1,0]]
```

That step advances both child orders simultaneously and is not a linear interleaving. Therefore the entire diagonal-inclusive root count is diagnostic only.

## Preserved lower-envelope correction

Even after the join path domain is repaired, a root compression cannot classify a quotient path solely from its retained lower envelope. The branch recorded eight lower-envelope quotient paths, all apparently successful, while the complete languages contain mixed success/failure behavior.

The corrected root theorem must therefore combine:

```text
ordinary join paths only
+ complete typical-pattern subclasses
+ exact success/failure reflection
+ multiplicity conservation
```
