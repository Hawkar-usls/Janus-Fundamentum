## Constructive P=NP track

```text
tractable local languages
-> exact semantic cut signatures or certified symbolic elimination
-> proof-carrying cross-class interface compression
-> certified merge and separator extraction
-> complete native and cross-language consequence bases
-> polynomial reachable quotient / symbolic factor construction
-> portfolio-guided semantic vtree discovery
-> SAT witness + UNSAT certificate
-> universal polynomial SAT algorithm
```

C037 and C037.1 supplied unary and equality negotiation. C037.2 proves that this
already spans every affine consequence of a Horn relation:

```text
Horn affine hull
= forced literals
+ equality-class spanning forest.
```

It also completely decides:

```text
MODELS(HORN) subseteq MODELS(AFFINE)
```

with either basis provenance or an explicit Horn separator model. Combined with
C037's opposite direction, Horn and affine residual messages can now be compared
constructively in both directions.

The complete 3-CNF `{NAND3,NEQ}` image gives the exact remaining boundary. Its Horn
module has no nontrivial affine consequence, all such consequences are injected,
and the negotiation still reaches:

```text
OPEN_AFFINE_CONSEQUENCE_COMPLETE
```

although the mixed conjunction is UNSAT. The missing information is conditional,
joint, and multirow; another unconditional XOR arity cannot supply it.

The negotiation gate is therefore:

```text
MULTIROW_HORN_AFFINE_INTERACTION_OR_PORTFOLIO_DECOMPOSITION
```

The structured route remains:

```text
C038 exact structured-vtree factor alignment
C039 fixed-k symbolic recursive separator compiler
C040 portfolio-guided semantic-vtree discovery
```

C037.2 proof traces are admissible C040 features, not decomposition proofs.
Equality classes may be clustered; an empty affine-hull basis may identify an
interface where unconditional XOR exchange is exhausted. C040 must still discover,
verify and charge the vtree and all factor operations.
