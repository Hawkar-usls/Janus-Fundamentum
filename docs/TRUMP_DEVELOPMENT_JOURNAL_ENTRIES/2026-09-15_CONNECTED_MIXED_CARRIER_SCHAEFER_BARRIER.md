# 2026-09-15 — Connected mixed-carrier Schaefer barrier

## Context

The preceding wide-interface work had already closed three important exact cases:

1. raw canonical feedback conditioning when the relevant interface width is logarithmic;
2. affine-syndrome quotienting when the complete frozen downstream contract factors through a low-rank GF(2) image;
3. exactly disconnected feedback dependencies as an additive factorized portfolio of separately sealed local carriers, with no Cartesian-product materialization.

The remaining surface was a connected wide interface containing mixed exact semantics outside one known carrier.

## Captain Obvious anti-loop

Historical review showed that this was not merely an implementation gap:

- exact open connected messages already projected supported unate/2CNF factors before physical separation, but left mixed 3CNF explicit;
- typed affine open messages compressed parity relations exactly but refused non-affine 3-OR;
- conditional typed backdoor/reachable-domain gates improved finite connected cores but did not establish a general polynomial connected mixed-core theorem;
- dense-positive-triples gave a representation-language depth lower bound but was itself dual-Horn and escaped under provenance-aware native semantics;
- provenance-preserving reverse morphs already restored Horn, dual-Horn, and 2CNF images to native polynomial solvers, leaving genuine mixed 3CNF OPEN.

Therefore the next question was whether polynomial exact composition of individually tractable carriers is even closed under connected mixing.

## Fixed witness language

Take two relations only:

- `OR2 = {01,10,11}`, individually bijunctive/2CNF;
- `EVEN_XOR3 = {000,011,101,110}`, individually affine GF(2).

The frozen checker verifies the combined language is none of: 0-valid, 1-valid, Horn, dual-Horn, bijunctive, affine. Explicit closure witnesses are recorded in the theorem/result artifacts.

By the preregistered source-bound Schaefer dichotomy, `SAT({OR2,EVEN_XOR3})` is NP-complete.

## Connected implication

Arbitrary instances of a fixed Boolean constraint language decompose into incidence-connected components in polynomial time, and satisfiability is the conjunction of component satisfiability.

Hence a polynomial exact mechanism for every connected instance of this fixed mixed language would solve the entire NP-complete language in polynomial time and therefore imply `P=NP`.

This is a conditional barrier statement only. It is not a proof that such a mechanism cannot exist and does not resolve P versus NP.
