The admission contract is exact: each recognized factor is one graph vertex; each residual Boolean variable is one undirected edge identity occurring in exactly two distinct factors; each local residual relation is exactly the set of Hamming-weight-two rows on its scope. Under this contract, relation satisfaction is identical to selected degree two at every vertex, hence to a spanning 2-factor. The preregistered carrier uses the classical Tutte f-factor-to-perfect-matching construction specialized to `f(v)=2`. For each graph vertex of degree `d`, it creates one incidence port `A(v,e)` per incident source edge and `d-2` slack vertices `B(v,j)`. Each source edge joins its two endpoint ports, while every local port is joined to every local slack vertex. A source 2-factor gives a perfect matching by taking cross-port edges for selected source edges and matching the remaining `d-2` local ports to the local slack vertices. Conversely, a perfect matching must consume all `d-2` slack vertices locally and therefore leaves exactly two ports per source vertex to be covered by cross-port edges, reconstructing a source 2-factor.

The implementation pins NetworkX `3.6.1` and uses `max_weight_matching(maxcardinality=True)` only as a polynomial matching engine. The engine's answer is never authority by itself.
