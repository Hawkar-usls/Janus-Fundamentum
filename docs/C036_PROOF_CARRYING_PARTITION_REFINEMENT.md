# C036 — Proof-Carrying Partition Refinement

**Status:** `CONSTRUCTIVE RESTRICTED LEMMA / P_VS_NP=OPEN`

## Purpose

C035 permitted a merge only when two residual states independently replayed to the same certified message. C036 adds the dual operation: a class may be split only when a deterministic polynomial-time extractor returns an explicit continuation under which two represented residuals differ.

The first complete separator languages are:

```text
Horn CNF residuals
affine GF(2) residuals
```

No unrestricted SAT or formula-equivalence oracle is called.

## Horn separator theorem

For Horn CNFs `F` and `G`, inequivalence is witnessed in one direction by a clause `C` of one formula that is not entailed by the other.

To test whether `F` entails `C`, conjoin `F` with the unit literals that falsify every literal of `C`. The result remains Horn and is solved by least-model forward chaining.

- SAT gives a complete assignment satisfying `F` and falsifying `C`, hence separating `F` from `G`.
- UNSAT records the Horn conflict trace and proves the directed entailment.

Checking every clause in both directions is polynomial and complete for Horn equivalence.

## Affine separator theorem

For affine systems `A` and `B`, inequivalence is witnessed by an equation of one system not implied by the other.

For each equation `r` of `B`, solve:

```text
A AND NOT r
```

where `NOT r` is the same GF(2) row with its right-hand side flipped. Gauss-Jordan elimination either returns:

- an assignment satisfying `A` and violating `r`; or
- a provenance certificate showing that `r` is implied by `A`.

The symmetric checks decide affine equivalence and extract a separator in polynomial time.

## Certified refinement

Given an explicit finite same-language state list, the refiner begins with one coarse block. A block is split only by a returned separator assignment. The split record contains:

```text
pair that triggered the split
separator assignment
directed violated clause or affine row
language-specific solver trace
resulting true and false subblocks
```

An independent verifier evaluates both states under the continuation and rejects a corrupt separator.

If the block mixes languages without a proved cross-language extractor, or if the separator-work budget is exceeded, the algorithm returns `OPEN`.

## Constructive advance

C035 supplied a sound merge congruence but had no constructive way to prove that two coarse states must differ. C036 proves that complete polynomial separator extraction exists inside two important message languages.

This is the same logical role played by distinguishing suffixes in automata minimization and by differing rows in a communication matrix, but every split here carries a SAT-interface-specific replayable certificate.

## Decisive boundary

The result does not solve the universal problem for two reasons.

1. The supplied explicit state list may already have exponential size.
2. Horn-plus-affine mixtures encode arbitrary 3-SAT, so a general cross-language separator extractor cannot be assumed merely because the two component languages are tractable.

The next missing theorem is:

```text
CROSS_LANGUAGE_SYMBOLIC_SEPARATOR_DISCOVERY
```

It must discover a polynomial family of symbolic continuations or a stronger compiled message language without deciding arbitrary residual SAT/equivalence by a hidden oracle.
