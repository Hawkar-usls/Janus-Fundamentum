# R5 E9 — Paley free-orbit post-RKPR linear nullity barrier

Date: 2026-09-29
Status: THEOREM / STRUCTURAL FALSIFIER
Authority: non-global; does **not** settle P vs NP

## Executive result

There is an infinite family of connected square linear cubic Exact-One source matrices that survive the rational-kernel projective-ratio quotient (RKPR) with no zero kernel coordinate and no pair of proportional kernel coordinates, while still having superlogarithmic rational nullity.

For every prime

\[
p\equiv 11\pmod{24},
\]

let \(T_p\) be the Paley tournament on \(\mathbb F_p\):

\[
u\to v \iff v-u\in Q_p,
\]

where \(Q_p\subset \mathbb F_p^\times\) is the subgroup of nonzero quadratic residues.

Let

\[
G_p=\{x\mapsto ax+b:a\in Q_p,\ b\in\mathbb F_p\}.
\]

The directed triangle

\[
\Delta=(0\to1\to2\to0)
\]

exists because \(1\in Q_p\) and, for \(p\equiv11\pmod{24}\), \(-2\in Q_p\).

Take the \(G_p\)-orbit of \(\Delta\), form the triangle-versus-arc incidence bipartite graph, and then take one connected component. Let \(A_p\) be the corresponding row-by-column 0/1 incidence matrix.

Write

\[
k_p=\operatorname{ord}_p(-2).
\]

Then every such connected component has

\[
n_p=p k_p
\]

rows and the same number of columns, every row and column has weight 3, the source is linear, and

\[
\boxed{\nu_{\mathbb Q}(A_p)\ge p-1\ge \sqrt{2n_p}-1.}
\]

Moreover every kernel-coordinate row is nonzero and no two distinct kernel-coordinate rows are rationally proportional. Hence RKPR performs no equality merge, no \(-2\)/\(-1/2\) pinning, and no illegal-ratio UNSAT termination on this family.

Therefore the universal shortcut

```text
post-RKPR + linear + connected
    => rational nullity O(log n)
    => enumerate 2^nu in polynomial time
```

is false.

This is a structural falsifier only. It does not imply hardness of the residual carrier and it does not prove P != NP.

## 1. Paley affine action and a free triangle orbit

For prime \(p\equiv3\pmod4\), the affine maps

\[
x\mapsto ax+b,\qquad a\in Q_p,
\]

preserve the Paley tournament. For prime order, this group is transitive on directed arcs; in fact it is regular on arcs because

\[
|G_p|=p\frac{p-1}{2}=|E(T_p)|.
\]

For \(p\equiv11\pmod{24}\):

- \(p\equiv3\pmod8\), so \((2/p)=-1\);
- \(p\equiv3\pmod4\), so \((-1/p)=-1\);
- therefore \((-2/p)=+1\).

Hence

\[
0\to1,\quad1\to2,\quad2\to0
\]

is a directed 3-cycle.

Any setwise stabilizer of a directed 3-cycle acts faithfully as a subgroup of the cyclic automorphism group \(C_3\) of that directed triangle. Thus a nontrivial stabilizer would have order 3.

But

\[
|G_p|=p(p-1)/2
\]

is not divisible by 3 when \(p\equiv11\pmod{24}\). Therefore \(\Delta\) has trivial stabilizer, so its orbit has exactly \(|G_p|\) triangles.

Rows and columns of the full orbit incidence matrix therefore have equal cardinality \(|G_p|\).

---

## 2. Cubic and linear source structure

Each row is one directed triangle, hence has weight 3.

The group \(G_p\) is transitive on columns (directed arcs), so every column has the same degree. Since the number of rows equals the number of columns and every row has degree 3, every column also has degree 3.

Thus the full orbit source is square cubic.

It is also linear. Two distinct directed triangles in a tournament cannot share two directed arcs: two shared arcs already determine the same three vertices, and the tournament fixes the orientation of the third arc. Therefore distinct source rows intersect in at most one column.

Every connected component of a 3-regular bipartite graph is again balanced and 3-regular, so each component gives a square linear cubic source matrix.

---

## 3. Exact connected-component size

Identify the base arc \(e_0=(0\to1)\) with the identity of \(G_p\). The three arcs of \(\Delta\) correspond to

\[
h_0=(1,0),\qquad
h_1=(1,1),\qquad
h_2=(-2,2),
\]

under the affine parametrization \((a,b):x\mapsto ax+b\).

The Levi component containing the identity is generated by \(h_1\) and \(h_2\).

Because \(h_1\) is translation by 1, the generated subgroup contains all translations. Also

\[
(1,-2)(-2,2)=(-2,0),
\]

so it contains multiplication by \(-2\). Hence the component subgroup is

\[
H_p=\{x\mapsto ax+b:a\in\langle-2\rangle,\ b\in\mathbb F_p\}.
\]

If

\[
k_p=\operatorname{ord}_p(-2),
\]

then

\[
|H_p|=pk_p.
\]

Rows and columns in one connected component are both indexed by a coset of \(H_p\), so

\[
\boxed{n_p=pk_p.}
\]

The number of connected components in the full orbit source is

\[
\frac{|G_p|}{|H_p|}=\frac{p-1}{2k_p}.
\]

## 4. Gradient kernel

Let \(D_p\) be the oriented vertex-to-arc coboundary map on the column arcs of one component:

\[
(D_p z)_{u\to v}=z_v-z_u.
\]

Every source row is a directed 3-cycle. Therefore the three differences telescope:

\[
(z_v-z_u)+(z_w-z_v)+(z_u-z_w)=0.
\]

Hence

\[
A_pD_p=0.
\]

The component contains every translated arc

\[
b\to b+1,
\]

because \(1\in\langle-2\rangle\). Thus its underlying undirected column graph contains the \(p\)-cycle generated by difference 1 and is connected. Therefore

\[
\operatorname{rank}_{\mathbb Q}(D_p)=p-1.
\]

Consequently

\[
\boxed{\nu_{\mathbb Q}(A_p)\ge p-1.}
\]

Since \(k_p\mid(p-1)/2\),

\[
n_p=pk_p\le\frac{p(p-1)}2<\frac{p^2}{2},
\]

so

\[
p>\sqrt{2n_p}
\]

and hence

\[
\boxed{\nu_{\mathbb Q}(A_p)\ge p-1>\sqrt{2n_p}-1.}
\]

This is superlogarithmic along the infinite prime progression \(p\equiv11\pmod{24}\).

## 5. RKPR is inert on the family

Let \(b_e\) denote the kernel-basis row associated with source column \(e\).

Because the gradient space \(\operatorname{im}D_p\) lies inside \(\ker A_p\), the coordinate functional for an arc \(e=(u\to v)\), restricted to this kernel subspace, is

\[
\ell_e(z)=z_v-z_u.
\]

This functional is nonzero, so no kernel-coordinate row can be zero.

If two distinct kernel-coordinate rows were rationally proportional, then their restrictions to the gradient subspace would also be proportional. But two forms

\[
e_v-e_u,\qquad e_{v'}-e_{u'}
\]

on vertex potentials modulo constants are proportional over \(\mathbb Q\) only when the unordered endpoint pairs are identical. A tournament contains only one directed arc for each unordered pair, so distinct source columns cannot satisfy this condition.

Therefore:

\[
\boxed{
\text{no zero kernel rows and no proportional pair of distinct kernel rows.}
}
\]

So RKPR has no projective reduction to perform.

---

## 6. Infinite family

Dirichlet's theorem gives infinitely many primes in the arithmetic progression

\[
p\equiv11\pmod{24},
\]

because \(\gcd(11,24)=1\).

Thus the construction yields arbitrarily large connected square linear cubic post-RKPR sources with

\[
\nu_{\mathbb Q}(A_p)=\Omega(\sqrt{n_p}).
\]

The lower bound is all that is required for the present falsifier; the exact nullity may be larger.

## 7. Exact Paley(11) control

For \(p=11\):

\[
k_{11}=\operatorname{ord}_{11}(-2)=5,
\qquad n=55.
\]

There is one connected component. Exact finite verification gives

\[
\operatorname{rank}_{\mathbb Q}(A_{11})=45,
\qquad
\nu_{\mathbb Q}(A_{11})=10=p-1.
\]

The equality can be certified without floating point:

1. the gradient kernel gives \(\operatorname{rank}_{\mathbb Q}(A_{11})\le45\);
2. reduction modulo 2 has rank 45, hence \(\operatorname{rank}_{\mathbb Q}(A_{11})\ge45\).

So the rational kernel is exactly the gradient space.

This also gives an exact UNSAT certificate for the full Paley(11) source. If \(x\in\{0,1\}^{55}\) satisfied \(A_{11}x=\mathbf1\), then

\[
y=3x-\mathbf1\in\ker A_{11}=\operatorname{im}D_{11}.
\]

Thus for every tournament arc \(u\to v\),

\[
z_v-z_u\in\{-1,2\}.
\]

Because every unordered vertex pair is an arc in one direction, every pair of distinct vertex potentials has absolute difference 1 or 2. A set of real numbers with all pairwise distances in \(\{1,2\}\) has size at most 3, contradicting the 11 vertices.

Therefore

\[
\boxed{A_{11}\text{ is Exact-One UNSAT}.}
\]

This UNSAT corollary is specific to the exact-kernel equality established at \(p=11\); it is not asserted for every member of the infinite family.

## 8. Scientific consequence

The following route is now forbidden:

```text
linear cubic source
  -> RKPR
  -> connected residual
  -> assume rational nullity O(log n)
  -> 2^nu enumeration
  -> polynomial universal solver
```

The Paley free-orbit family survives all first three premises and has

\[
\nu_{\mathbb Q}=\Omega(\sqrt n).
\]

Therefore any successful universal algorithm must exploit structure beyond rational nullity size and projective proportionality. In particular it must attack the remaining global endpoint-syndrome / affine-cycle coupling itself, or find a different representation-changing polynomial quotient.
