## 1. Statement

For every prime

```text
q >= 11,
q = 3 (mod 8),
```

there is an explicit connected square linear cubic Exact-One source `A_q` such that

```text
RKPR(A_q) is inert,
nullity_Q(A_q) = q-1,

```

If `n_q` is the number of variables/rows, then

```text

```

Since there are infinitely many primes `q=3 (mod 8)`, this is an infinite family. Therefore


does **not** imply rational nullity `O(log n)`.

This closes the post-RKPR low-nullity route as a universal polynomial strategy.

It does **not** prove P=NP; the family itself has a short polynomial UNSAT certificate.

## 2. Paley arithmetic

Work in `F_q = Z/qZ`. Let `R` be the nonzero quadratic residues.

Because `q=3 (mod 4)`, `-1` is a quadratic nonresidue, so for every nonzero difference exactly one of `d,-d` lies in `R`; this is the Paley tournament orientation

```text
x -> x+d   for d in R.
```

Because `q=3 (mod 8)`, the quadratic-character identity for `-2` gives

```text
-2 in R.
```

Let

```text
C = < -2 > <= R
m = |C| = ord_q(-2).
```

More generally any multiplicative coset `d0 C` inside `R` works; fix `C` for definiteness.

## 3. Variables and source rows

Variables are the Paley arcs whose directed differences lie in `C`:

```text
E(x,d) = (x -> x+d),
 x in F_q,
 d in C.
```

Thus

```text
n = q m.
```

For every `(x,d)` create one source row

```text
T(x,d) = {
  E(x,d),
  E(x+d,d),
  E(x+2d,-2d)
}.
```

Its three underlying vertices are

```text
x, x+d, x+2d.
```

The directed differences around the triangle are

```text
d, d, -2d,
```

all in `C`. Hence every `T(x,d)` is a directed cyclic triangle of the Paley tournament.

There are exactly `q m=n` rows.

## 4. Exact cubic degree

Fix a variable `E(a,e)` with `e in C`.

It occurs in exactly these three rows:

```text
T(a,e)              first d-edge
T(a-e,e)            second d-edge
T(a+e,-e/2)         closing (-2d)-edge
```

because `-e/2` belongs to `C` (the set `C` is a group generated by `-2`).

The three rows are distinct for `q>=11`. Therefore every column has degree 3; every row has size 3 by construction.

So `A_q` is square and cubic.

## 5. Linearity

Every source row is the edge set of a simple graph triangle on

```text
{x,x+d,x+2d}.
```

Two distinct graph triangles cannot share two edges. Also no selected directed arc and its reverse both occur because `C subset R` while `-R` is the nonresidue set.

The representation `T(x,d)` has no duplicate row for `q>=11`: the only reversal of the same three-term arithmetic progression replaces `d` by `-d`, but `-d notin R`, hence `-d notin C`.

Therefore distinct source rows intersect in at most one variable. The source is linear.

## 6. Connectedness

For fixed `d in C`, the rows `T(x,d)` contain both

```text
E(x,d)
and
E(x+d,d).
```

As `x` ranges over `F_q`, these incidences connect all `q` variables of difference class `d`, because addition by nonzero `d` is a single `q`-cycle when `q` is prime.

Each `T(x,d)` also meets difference class `-2d`. Since `C` is one orbit under multiplication by `-2`, all `m` difference classes are linked.

Hence the Levi graph of `A_q` is connected.

## 7. Root-difference kernel

Define an `n x q` matrix `H` with one row per variable:

```text
h_(x,d) = e_(x+d) - e_x.
```

Every source row telescopes:

```text
h_(x,d)
+ h_(x+d,d)
+ h_(x+2d,-2d)
= 0.
```

Therefore

```text
A_q H = 0.
```

The underlying graph of the rows of `H` is connected (indeed one fixed difference class is already a `q`-cycle), so its oriented incidence matrix has

```text
rank_Q(H)=q-1.
```

Thus

```text
nullity_Q(A_q) >= q-1.
```

## 8. Exact nullity by additive Fourier decomposition

The source is invariant under simultaneous translation of the `x` coordinate. Work over `C` and let

```text
omega = exp(2 pi i / q).
```

For additive frequency `k in F_q`, write a mode as

```text
y_(x,d) = omega^(k x) z_d.
```

The kernel equation from row `T(x,d)` becomes

```text
(1 + omega^(k d)) z_d
+ omega^(2 k d) z_(-2d)
= 0.                    (F_k)
```

Since multiplication by `-2` is one cycle on `C`, `(F_k)` is a first-order recurrence around that cycle.

### Frequency k=0

The recurrence is

```text
z_(-2d) = -2 z_d.
```

After one full orbit of length `m`,

```text
z_d = (-2)^m z_d.
```

Because `(-2)^m != 1` as an ordinary complex number, only `z=0` is possible. Thus the zero-frequency kernel has dimension 0.

### Every frequency k != 0

The recurrence determines every `z_d` from one starting value, so its kernel dimension is at most 1.

A nonzero solution is explicit:

```text
z_d = omega^(k d) - 1.
```

Indeed

```text
(1+t)(t-1) + t^2(t^(-2)-1)
= t^2-1 + 1-t^2
= 0,
```

where `t=omega^(k d)`. Since `k,d` are nonzero mod `q`, `t != 1`, so this mode is nonzero.

Therefore every one of the `q-1` nonzero frequencies contributes exactly one kernel dimension.

Hence

```text
nullity_C(A_q)=q-1.
```

`A_q` has rational entries, so rank is unchanged under extension from `Q` to `C`. Therefore

```text
boxed: nullity_Q(A_q)=q-1.
```

Together with `A_q H=0` and `rank(H)=q-1`, this also proves

```text
ker_Q(A_q)=col_Q(H).
```

## 9. RKPR is exactly inert

On the root-potential kernel, coordinate `E(x,d)` is the functional

```text
e_(x+d)-e_x.
```

No such functional is zero.

Two distinct selected arcs cannot produce proportional root vectors over `Q`: vectors of the form `e_v-e_u` are proportional only for the same unordered endpoint pair, while the Paley tournament selects exactly one orientation of each pair.

If two full kernel coordinate rows were proportional, their restrictions to the root-potential subspace would also be proportional. Contradiction.

Therefore

```text
zero rational kernel rows      = 0
proportional kernel-row pairs  = 0
```

for every member of the family.

So the existing Rational Kernel Projective Ratio Pinning Quotient performs no pin, merge, or illegal-ratio rejection:

```text
RKPR(A_q)=A_q
```

up to relabeling.

## 10. Exact-One UNSAT

Assume a Boolean witness

```text
x in {0,1}^n,
A_q x = 1.
```

Because every source row has size 3,

```text
A_q ((1/3)1)=1.
```

Hence

```text
y=x-(1/3)1 in ker_Q(A_q)=col_Q(H).
```

There is a vertex potential `alpha` such that

```text
y_(a,d)=alpha_(a+d)-alpha_a.
```

Let `beta=3 alpha`. Then on every selected directed arc

```text
beta_(a+d)-beta_a
= 3 x_(a,d)-1
in {-1,2}.
```

Fix any `d in C`. The arcs

```text
a -> a+d
```

form one directed cycle of length `q`. Summing the potential increments around it gives zero. If `s` of its `q` variables equal 1, then

```text
0 = 2s - (q-s) = 3s-q.
```

Thus `q=3s`, impossible because the prime `q>=11` is not divisible by 3.

Therefore every `A_q` in the family is Exact-One UNSAT.

This certificate is linear-size and does not enumerate its `q-1` dimensional rational kernel.
