## 2. Source-bound language

The matrix below is a binary two-dimensional cyclic-code generator in the
classical sense of Imai: code arrays are indexed by a finite torus and the code
is invariant under cyclic shifts in both coordinates.

Source:
Hideki Imai, *A Theory of Two-Dimensional Cyclic Codes*, Information and
Control 34(1), 1--21 (1977), DOI 10.1016/S0019-9958(77)90232-7.

The general 2D-cyclic language is therefore source-bound.  No novelty is
claimed for representing a torus translation code by a bivariate polynomial

## 4. Exact cogirth and circuit girth

## 6. Exact terminal-leaf certificate

Connectivity is checked in the dual representation, whose rank is only seven.

The checker enumerates every flat generated by subsets of the fifty dual
ground elements.  There are exactly

```
23,250
```

such flats.

For each flat-side partition it evaluates the matroid connectivity function

```
lambda(X)=r(X)+r(E-X)-r(M).
```

Result:

```
1/2-separations = 0,
exact 3-separations with both sides >=3 = 0.
```

Completeness of the flat-side census uses the already verified absence of
triangles and triads.  If an exact 3-separation were not closed on one side,
move an opposite-side element lying in its closure across the separation.
In a 3-connected matroid the connectivity cannot drop below two.  Repeating
either reaches a closed side or leaves a three-element side; the latter would
be a triangle or triad, which is impossible here.

Therefore the parent itself is a source-valid terminal leaf for the standard
1/2/3-sum route.

## 8. Source-bound terminal lanes excluded

### no-S8

Excluded by the explicit minor above.

### graphic / even-cycle

Graphic has `q_graph=0`; an even-cycle matroid is a one-row lift and has
`q_graph<=1`.  Both are excluded by `q_graph>=19`.

### graft

In a graft representation, deletion of the graft element is graphic.

Every deletion of this parent has

```
rank=43,
cogirth=3.
```

The rank is unchanged because the whole ground set is a binary cycle, hence
there are no coloops.  Puncturing a distance-four cocycle code gives distance
at least three, while every coordinate lies in a weight-four cubic star, so
the deletion cogirth is exactly three.

If any deletion were graphic, its simple graph would have 49 edges and
graphic rank 43.  After removing isolated vertices its average degree is
below three, so some non-isolated vertex has degree at most two.  Its incident
cut contains a bond of size at most two, contradicting cogirth three.

Thus the graft terminal lane does not apply.

### even-cut / cographic

An even-cut representation would place a graph cycle-space of dimension at
least

```
43-1=42
```

inside `C*(M)`.  On fifty ground elements that graph has graphic rank at
most eight.

Because every nonzero parent cocycle has weight at least four, this graph is
simple and triangle-free.  A componentwise Mantel bound gives at most twenty
edges at total graphic rank eight.  The checker verifies the integer-partition
maximum exactly.

But the parent has fifty elements.  Contradiction.

Hence the even-cut lane, including the cographic special case, is excluded.

## 9. Random regular-rank anti-loop

A separate source check prevents a tempting wrong generalization.

Coja-Oghlan and Gao determine the asymptotic rank of sparse random finite-field
matrices with prescribed row/column degrees.  For the square doubly
3-regular case,

```
D(x)=K(x)=x^3
```

and their variational function simplifies to

```
Phi(alpha)
=
-alpha^3 (alpha-1)^2 (alpha+2)
<=0.
```

Thus the random-matrix rank ratio tends to one.

This is **not** a high-`q_graph` theorem.  Rank alone is the wrong currency:
if a square cubic `H` is actually full rank, then `[H|1]` has rank `n`
on `n+1` elements and its only dependency is the all-ground-set cycle;
the matroid is just a graphic circuit matroid.

Freeze:

```
RANDOM (3,3) HIGH RANK
ALONE
!=
HIGH q_graph LEVERAGE.
```

The missing ingredient is simultaneous sparse cubic generation and exclusion
of weight-one/two cocycles, i.e. a nontrivial code-distance constraint.
