## 1. Purpose

The Strong Splitter theorem permits a special regime in which, once the current
rank has reached the final rank, a sequence may contain a long tail of
rank-preserving single-element extensions.

This artifact does **not** claim that such a tail is intrinsically hard, and it does
not claim an exponential lower bound on every exact signature.

It asks the first exact killer-control question:

> What information must an exact shortest-`f` update consume when a new
> rank-preserving column is added?

The answer is an exact min-plus syndrome recurrence.

## 2. Binary representation and distinguished-element distance

Let a rank-`r` binary matroid prefix be represented by columns in
`GF(2)^r`. Fix a distinguished element `f` with column vector `b_f`.

Remove `f` from the list of usable columns and define

```
d_M(s)
=
min {|X| :
     X subset of E(M)-{f},
     XOR_{e in X} b_e = s }.
```

Use `+infinity` if no such set exists.

Then

```
shortest_f(M)
=
1 + d_M(b_f).
```

Why the minimum dependency is a circuit:

if a minimum set `{f} union X` contained a proper dependent subset containing
`f`, that subset would give a smaller representation of `b_f`. If it contained
a proper dependent subset avoiding `f`, deleting that zero-sum subset from
`X` would again give a smaller representation of `b_f`.

Thus the minimum dependency through `f` is inclusion-minimal.

## 3. Single rank-preserving extension recurrence

Add one new element `e` whose column is `v in GF(2)^r`.
The rank is unchanged.

Every minimum representation of syndrome `s` either:

1. does not use `e`, with cost `d_M(s)`; or
2. uses `e`, after which the old columns must represent `s+v`, with cost
   `1+d_M(s+v)`.

Therefore exactly

```
d_{M+e}(s)
=
min(
    d_M(s),
    1 + d_M(s+v)
).
```

In particular,

```
shortest_f(M+e)
=
1 + min(
        d_M(b_f),
        1 + d_M(b_f+v)
    ).
```

So the scalar `d_M(b_f)` is not, by itself, an update-closed state: the next
extension may require a shifted syndrome cost.

## 4. Exact k-extension tail formula

For a rank-preserving extension tail with column vectors

```
v_1,...,v_k
```

repeated application of the single-step identity yields

```
d_k(s)
=
min over T subseteq {1,...,k}
[
    |T|
    +
    d_0(
        s + XOR_{i in T} v_i
    )
].
```

Equivalently, if

```
c_T(u)
=
minimum number of tail columns whose XOR is u,
```

then

```
d_k(s)
=
min_u [
    c_T(u) + d_0(s+u)
].
```

This is a min-plus convolution over the syndrome subgroup generated by the
extension vectors.

This identity is exact and includes witness reconstruction by storing a minimizing
tail subset plus a witness for the selected prefix syndrome.

## 5. What this proves — and what it does not

It proves:

```
TARGET COST ONLY
=
NOT AN ALGEBRAICALLY CLOSED
GENERIC EXTENSION INTERFACE.
```

An exact extension update naturally asks for shifted syndrome information.

It does **not** prove:

```
POLYNOMIAL SIGNATURE IMPOSSIBLE.
```

The shifted cost function may admit a compact representation on the special JANUS
origin class. Discovering such a representation is precisely the active task.

Likewise, the explicit `2^k` subset formula is not an algorithmic lower bound.
Different subsets can have the same XOR, and the resulting min-plus function may
compress.

## 6. Exact scalar-state countercontrol

The checker contains a rank-4 unrestricted binary control.

Take distinguished syndrome

```
f = 1111_2 = 15
```

and two prefixes

```
B1 = {0001,0010,1100}
B2 = {0001,0100,1010}.
```

Both have

```
d_B1(f) = d_B2(f) = 3.
```

Now add the same extension column

```
v = 0011.
```

For `B1`,

```
d_B1(f+v)=d_B1(1100)=1,
```

while `1100` is unreachable from `B2`.

Hence after the same extension,

```
d_{B1+v}(f)=2,
d_{B2+v}(f)=3.
```

Thus two prefixes with the same scalar target cost can require different exact
updates under the same extension.

Scope ceiling:

this is an unrestricted binary-matroid countercontrol. It does not establish that
the same pair occurs inside the frozen 3-connected cubic-origin survivor.

## 7. Concrete S8 rank-saturated control

For a source-standard representation of `S8` over `GF(2)`, use the columns

```
{1,2,4,8,14,13,11,15}
```

under the checker bit convention. This is the Sage catalog matrix

```
[I4 | 0111,1011,1101,1111]
```

up to row/bit ordering.

The seven missing nonzero rank-4 vectors are

```
3,5,6,7,9,10,12.
```

The checker adds them in that order and verifies exactly that every intermediate
binary matroid:

- remains rank 4;
- is 3-connected by the connectivity-function test
  `lambda(X)=r(X)+r(E-X)-r(M) >= 2` whenever both sides have size at least two.

The final set is all 15 nonzero vectors of `GF(2)^4`, i.e. the projective
geometry `PG(3,2)`.

Therefore:

```
S8
-> seven consecutive rank-preserving
   3-connected extensions
-> PG(3,2)
```

is a concrete finite witness that the rank-saturated-extension exception in the
Strong Splitter discussion is operational rather than merely syntactic.

This is **not** an asymptotic tail family and is not evidence of exponential state
growth.

## 8. Consequence for the universal algorithm

The source-bound no-`S8` decomposition machinery already uses only small
separator-conditioned shortest-circuit data across 1/2/3-sums.

A rank-saturated Splitter extension is qualitatively different: it is not a
small-separator composition. Its exact update is a syndrome shift.

Therefore the next object is now sharper than “find a polynomial boundary
signature”:


it with coextension updates into a full Splitter-sequence algorithm.
