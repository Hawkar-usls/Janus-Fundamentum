## 1. Exact side-bit encoding of signed NAE3

For one signed NAE3 row a in {0,+1,-1}^n let

ell(a)=1-n(a),

where n(a) is the number of -1 incidences.

Because every row has exactly three signed literals, its upper NAE bound is

u(a)=p(a)-1=ell(a)+1.

Therefore for Boolean x:

x satisfies the signed NAE row

iff

a x = ell(a) + s

for one side bit s in {0,1}.

For a signed NAE matrix A this gives the exact integer equation

A x = ell + s,

with x Boolean and s Boolean.

The side vector records which of the two integer NAE levels each row occupies.

## 2. Smith quotient for a full-rank row basis

Choose n independent rows B of an m x n signed NAE matrix.

Let U B V = D be the Smith normal form over Z, with

D=diag(d1,...,dn), d_i | d_{i+1}.

For any binary side word s_B, the basis equations are

B x = ell_B + s_B.

An integer lift x exists iff the transformed right-hand side satisfies the SNF divisibility conditions

d_i divides [U(ell_B+s_B)]_i

for every i.

Thus the integer-lift obstruction of the interacting signed rows is represented exactly by a finite abelian torsion code on the row-side bits.

Important firewall:

SNF integrality is only a lattice filter. In general an integer lift may lie outside {0,1}^n, so every surviving side word must still be lifted and checked against the Boolean box and all remaining rows.

No universal polynomial algorithm is claimed.
