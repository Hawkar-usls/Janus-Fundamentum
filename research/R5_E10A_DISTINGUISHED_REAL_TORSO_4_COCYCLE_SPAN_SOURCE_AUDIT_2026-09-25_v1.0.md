## G2 — exact normal forms / canonical external languages

### N1 — sparse all-ones parity-check normal form

The 4-cocycle-span promise is equivalent to existence of a representation

```
[H | 1]
```

whose rows span `C*(N)` and satisfy

```
rowwt(H) <= 3.
```

Indeed, every promised generator has the form

```
{f} union T_i,
|T_i| <= 3,
```

and the incidence vectors of the `T_i` form the rows of H.  Conversely every
row of `[H|1]` is an f-containing cocycle of total support at most four.

Thus the generic optimization language is

```
min |x|
subject to Hx = 1 over GF(2),
with check arity <= 3.
```

This is a Min-Ones affine-CSP / nearest-codeword language.

### N2 — 3-connected strengthening

In a 3-connected matroid every cocircuit has size at least three.

A nonzero cocycle of size at most four cannot be the disjoint union of two
nonempty cocircuits, since that would require at least six elements.

Therefore every promised generator in the actual 3-connected survivor is a
cocircuit:

```
C*(N)
=
span of f-containing TRIADS and QUADS.
```

Dually, the cycle space of `N* / f` is generated by cycles of size at most
three (parallel-pair cycles may appear after contraction).

This is a useful exact normalization but is not by itself a solver theorem.

## G3 — public source exhaustion

### S1 — Min-Ones classification: arity-three affine optimization is hard

Khanna--Sudan--Trevisan--Williamson,
*The Approximability of Constraint Satisfaction Problems*,
SIAM J. Comput. 30(6), 1863--1920 (2001),
DOI 10.1137/S0097539799349948,
classify Min-Ones Boolean CSPs.

For affine constraint languages that are not width-2 affine, Min-Ones lies in
the Nearest-Codeword-complete/hard branch.

The ternary odd-parity relation

```
x xor y xor z = 1
```

is affine, is not 0-valid, and is not width-2 affine.  Therefore generic

```
min |x| subject to ternary XOR equations
```

is not a polynomial lane supplied by affine satisfiability / Gaussian
elimination.

JANUS consequence:

This does **not** establish hardness of the exact JANUS intersection with

### S2 — sparse LDPC decoding is an adjacent stronger warning

Santhi,
*Sparse Representations for Codes and the Hardness of Decoding LDPC Codes*,
ISIT 2008, DOI 10.1109/ISIT.2008.4594994,
gives a polynomial reduction from binary MLD to weighted MLD on (3,3)-LDPC
codes.

This reinforces that bounded parity-check degree, even on both sides, does not
make optimal decoding generically easy.

But the theorem is weighted MLD and does not bind the exact JANUS
distinguished all-ones syndrome, two-row torso structure, or literal-placement
promise.

Classification:
`SPARSE_DECODING_HARDNESS_DONOR__NO_EXACT_JANUS_COLLISION`.

### S3 — bounded cocycle-basis size has an existing matroid invariant

Bill Jackson,
*Counting 2-connected deletion-minors of binary matroids*,
Discrete Math. 313 (2013), 1262--1266,
DOI 10.1016/j.disc.2012.11.003,
defines

```
Lambda(M)
=
min over cocycle-space bases B
max_{K in B} |K|.
```

The NM-0012 promise implies immediately

```
Lambda(N) <= 4.
```

Jackson uses bounded `Lambda` to bound the number of fixed-size circuits and
2-connected deletion-minors containing a fixed element.

This is a genuine source collision with the **unanchored bounded cocycle-basis**
part of the promise.

The source does not provide:

- a shortest-f/coset-leader solver for bounded Lambda;
- the stronger condition that every basis cocycle can be chosen to contain the
  same distinguished f;
- a two-row-lift contraction theorem.

Classification:
`BOUNDED_COCYCLE_BASIS_SOURCE_BOUND__NO_SOLVER_CLOSURE`.

### S4 — triangle-generated dual contraction is not the same as chordal matroid

Douthitt--Oxley,
*Chordal matroids arising from generalized parallel connections II*,
Adv. Appl. Math. 164 (2025), 102833,
DOI 10.1016/j.aam.2024.102833,
characterize GF(2)-chordal matroids via generalized parallel connections,
forbidden flats, and perfect-elimination-type structure.

The JANUS promise only implies that the cycle space of `N*/f` is generated
by cycles of size at most three.

That is weaker than GF(2)-chordality.

Finite control: the graphic wheel `W_4` has cycle space generated by its four
triangles, while the rim `C_4` is a circuit-flat obstruction to chordality.
Hence:

```
TRIANGLE-GENERATED CYCLE SPACE
!=
GF(2)-CHORDAL.
```

Classification:
`CHORDAL_MATROID_STRONG_ADJACENT_DONOR__NO_EXACT_COLLISION`.

### S5 — triads/fans/small-cocircuit structure is source-bound but not a complete classification

The literature on 3-connected binary matroids contains extensive structure for
triads, vertex-triads, fans, minimally 3-connected matroids, and splitter
sequences.  Examples include:

- Wu, *On Vertex-Triads in 3-Connected Binary Matroids*;
- Gomes--Lemos, *The number of elements belonging to triads in 3-connected
  binary matroids*;
- modern splitter theorems involving inner fans.

These are useful donors because the actual NM-0012 generators are anchored
triads/quads.

No located source gives a classification or polynomial shortest-f algorithm for

```
3-connected binary N
whose entire cocycle space is spanned by
triads/quads all containing one fixed f,
```

still less for the intersection with the two-row graph-lift/S8 lineage.

Classification:
`SMALL_COCIRCUIT_STRUCTURE_SOURCE_BOUND__SCOPED_GAP_SURVIVES`.
