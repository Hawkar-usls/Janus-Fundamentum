## 1. Primal graph separation lemma

For a Boolean CSP instance I, let P(I) be its primal graph:
- one vertex per Boolean variable;
- two variables are adjacent if they occur together in one constraint.

Let B be a vertex separator. After removing B let the remaining connected components be C_1,...,C_m.

Every constraint scope induces a clique in the primal graph. Therefore no constraint can contain variables from two distinct C_i outside B.

Hence I factors exactly into one boundary-only part I_B and subinstances I_i using only C_i union B.

For one component define its exact boundary extension relation

    R_i = { beta in {0,1}^B : I_i[beta] is satisfiable }.

Then I is satisfiable iff there exists beta on B satisfying I_B and belonging to every R_i.

If |B| <= 2, each exact message has at most 2^|B| <= 4 states.

Witness reconstruction stores one child witness/lift certificate for each accepted boundary state.

## 2. Universal low-order decomposition

Disconnected components give adhesion zero.
Articulation points give adhesion one.
Inside each biconnected block, separation pairs give adhesion two.

Hopcroft-Tarjan give a polynomial, in fact linear-time, decomposition into triconnected components. SPQR trees package this into a linear-size tree of series, parallel, rigid/3-connected and trivial pieces.

Thus every overlay instance admits a polynomially constructible decomposition whose unresolved rigid torsos are 3-connected and whose parent interfaces have size at most two.

## 3. Solver-lifting meta-theorem

THEOREM E9-A2C1.

Assume an exact polynomial procedure TORSO_SOLVE for every rigid 3-connected torso generated by this decomposition, including arbitrary binary relations placed on virtual separator edges by child messages.

For the parent separator B, |B|<=2, TORSO_SOLVE returns the exact extendable subset R_T of {0,1}^B plus reconstructible witnesses.

Then the whole original CSP is solvable exactly in polynomial time.

Proof:
Root the decomposition tree and process bottom-up.
Each child exposes at most four allowed assignments on its virtual separator pair.
Treat this table as one fixed binary relation on the corresponding parent vertices.
Series/parallel/trivial pieces use constant-state joins.
At a rigid torso call TORSO_SOLVE.
The outgoing message again has at most four states.
The decomposition has polynomial (standard SPQR: linear) total size.
At the root, nonemptiness decides SAT; stored witnesses lift top-down.
QED.
