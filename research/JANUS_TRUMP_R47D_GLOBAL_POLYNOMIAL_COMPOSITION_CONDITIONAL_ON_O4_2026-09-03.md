# JANUS TRUMP R47D — global polynomial composition conditional on O4

Status: **conditional theorem**. This is not a SAT-in-P proof because O4 universal coverage remains OPEN.

## Statement

Let the original 3-CNF input have encoding length `n`. Assume the frozen TRUMP transition system has:

1. local semantic correctness / independently replayable terminal or equisatisfiable transition certificates;
2. every accepted nonterminal transition ends at a strictly smaller frozen lexicographic `CLV=(C,L,V)` state;
3. the theorem-safe polynomial resource envelope of R47B for construction, normalization, certificate generation and verification of every inspected macro candidate;
4. **O4**: every reachable nonterminal residual state has an accepted certified transition discoverable by the frozen deterministic scan.

Then TRUMP halts with the correct SAT/UNSAT answer in `n^{O(1)}` work.

## Proof

### A. Accepted trajectory height

For initial clause count `C0` and variable count `V0`, the previously sealed CLV-height lemma bounds every accepted final state by

`0 <= C <= C0`, `0 <= V <= V0`, `0 <= L <= C0*V0`.

Every accepted nonterminal transition strictly decreases lexicographic CLV. Hence the number of accepted nonterminal transitions is less than

`H = (C0+1)*(C0*V0+1)*(V0+1)`.

Because the encoding length dominates the number of clauses and distinct variables, `C0,V0 <= n`, so `H = O(n^4)`.

### B. One inspected candidate is polynomial in the original input

At any accepted state, `C <= n`, `V <= n`. Exact DP on one pivot checks at most `C^2/4 = O(n^2)` parent pairs and creates a pool with `O(n^2)` clauses, each using no fresh variables and therefore at most `n` literals. Peak DP literal mass is `O(n^3)`.

R47B proves that R33 on a represented input with `C'` clauses and `V'` variables has a theorem-safe step cap

`H_R33=(C'+1)*(2*C'*max(1,V')+1)*(V'+1)=poly(C',V')`.

Its per-inspection rules are all polynomial scans/pair operations over the represented formula. Substituting `C'=O(n^2), V'<=n` remains polynomial in `n`.

RUP on literal mass `L'=O(n^3)` and at most `n` variables has the coarse R47B producer bound `O(n*(L')^3)=O(n^10)`; independent replay is polynomial. Affine recognition/GF(2), Horn forward chaining and 2-SAT SCC lanes are polynomial in their represented input. Model reconstruction and hashing/serialization touch only polynomial-size histories/records generated by these polynomial procedures.

Therefore there exists a fixed polynomial `Q(n)` bounding construction + normalization + certificate generation + independent verification of one inspected candidate.

### C. Candidate discovery scan is polynomial

A deterministic state scan considers at most the current `V <= n` variables. Even the legacy all-variable selector therefore costs at most `n*Q(n)`, polynomial. A first-certified prefix policy can only reduce this work; global argmin is not required for this composition result.

By O4, each nonterminal state reaches an accepted transition within that polynomial scan.

### D. Whole run

There are fewer than `H=O(n^4)` accepted nonterminal transitions. Each transition is discovered and certified in at most `n*Q(n)` work. The final terminal lane is polynomial. Hence total work is bounded by

`O(n^4) * O(n*Q(n)) + poly(n) = n^{O(1)}`.

Correctness follows by composing the independently certified semantics of every transition with the independently verified terminal answer.

Therefore, **conditional on O4**, TRUMP is a deterministic polynomial-time SAT/3-SAT algorithm.
