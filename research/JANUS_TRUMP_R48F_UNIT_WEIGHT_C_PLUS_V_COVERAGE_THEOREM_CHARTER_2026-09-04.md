## Definition — unit-weight safe successor

Let

`Psi(F)=C(F)+V(F)`.

A certified nonterminal successor `F -> F'` is **unit-weight safe** if:

1. one existing pivot is eliminated by exact Davis-Putnam projection;
2. exact-DP independent replay passes;
3. the frozen R47M R33/affine/RUP/SA-BVE joint normalization is executed to terminal or joint fixpoint;
4. the selected full R47M replay passes;
5. no fresh variable appears;
6. `V(F') < V(F)`;
7. `Psi(F') <= Psi(F)`.

Equivalently, writing

`DeltaC=C(F')-C(F)`

and

`DeltaV=V(F)-V(F')>0`,

unit-weight safety is

`DeltaC <= DeltaV`.

Equivalently,

`a_req(F,v) <= 1`.

A verified semantic terminal is accepted immediately and does not need to satisfy a nonterminal weighted inequality.

## Lemma 1 — unit-weight safety gives a linear persisted clause envelope

If every selected nonterminal step is unit-weight safe, then

`C(F_t)+V(F_t) <= C0+V0`.

Since clause count is nonnegative,

`C(F_t) <= C0+V0`.

For a root encoding of length `N`, both `C0<=N` and `V0<=N`, so

`C(F_t) <= 2N`.

Thus every persisted state has only `O(N)` clauses.

## Lemma 2 — persisted literal mass is polynomial

No fresh variables are introduced, so

`V(F_t)<=V0<=N`.

A canonical tautology-free clause has at most one literal per remaining variable. Hence

`L(F_t) <= C(F_t)V(F_t) <= (C0+V0)V0 = O(N^2)`.

## Lemma 3 — every exact-DP probe is polynomial under the unit-weight envelope

At a persisted state with

`C<=C0+V0=O(N)`,

one exact-DP pivot with `p` positive and `n` negative parents examines at most

`p n <= C^2/4 = O(N^2)`

parent pairs and produces at most `O(N^2)` raw non-tautological resolvents.

Each resolvent has at most `V0-1=O(N)` literals, so the one-step forced-DP literal mass is `O(N^3)`.

The already-frozen R47M normalization and independent verification envelopes are polynomial in that one-step representation size.

The transient representation is not persisted unless the normalized successor returns to the unit-weight envelope.

## Lemma 4 — discovery is polynomial and does not enumerate projection sequences

At each persisted state, scan current variables in deterministic canonical order, compute the certified exact-DP-plus-R47M candidate for each pivot, and accept a verified terminal or the first unit-weight-safe candidate.

There are at most `V0<=N` pivots per state and at most `V0<=N` selected nonterminal states because variable count strictly decreases.

Therefore the whole run performs at most `V0^2<=N^2` candidate probes.

No depth-k projection-sequence enumeration is needed.

## Conditional theorem — Universal Unit-Weight Coverage implies polynomial 3-SAT

Assume:

> For every valid 3-CNF root `F0` and every reachable persisted normalized nonterminal state `F` generated by the deterministic unit-weight grammar, there exists a polynomially discoverable certified pivot whose exact-DP-plus-frozen-R47M result is either a verified semantic terminal or a unit-weight-safe nonterminal successor.

Then deterministic unit-weight first-certified projection decides 3-SAT in polynomial time.

### Proof

- Correctness/equisatisfiability composes through exact DP and every frozen certified normalizer.
- Variable count gives at most `V0<=N` selected nonterminal steps.
- Lemma 1 bounds persisted clauses by `O(N)`.
- Lemma 2 bounds persisted literal mass by `O(N^2)`.
- Lemma 3 makes every candidate probe and independent verification polynomial.
- Lemma 4 bounds the number of probes by `O(N^2)`.
- A verified SAT terminal carries model reconstruction backward through the certified chain; a verified UNSAT terminal carries the certified equisatisfiable/refutational chain.

Therefore total work is `N^{O(1)}`.

This is a conditional composition theorem, **not** a proof that the universal premise is true.

## Exact falsifier for the universal unit-weight premise

A single reachable persisted normalized nonterminal state `F` refutes Universal Unit-Weight Coverage if all of the following hold:

1. no existing certified terminal fires on `F`;
2. for every current pivot `v`, construct the frozen exact-DP-plus-R47M candidate;
3. every candidate certificate/replay required by the frozen authority passes or the candidate is inapplicable;
4. there is no terminal candidate;
5. every certified nonterminal variable-decreasing candidate satisfies

   `C(F_v)-C(F) > V(F)-V(F_v)`;

A stronger falsifier is a state with no certified variable-decreasing R47M candidate at all.
