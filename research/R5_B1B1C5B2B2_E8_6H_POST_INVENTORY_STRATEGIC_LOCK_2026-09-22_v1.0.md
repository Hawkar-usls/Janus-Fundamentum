## Five anti-loop laws

### A1 — Compactness is not tractability

```text
COMPACT REPRESENTATION
!=
TRACTABLE CONSISTENCY
```

ECNF is the canonical E8 control: it survives both concrete representation blow-ups audited in E8, yet terminal SAT remains NP-hard.

### A2 — Closure is not a size theorem

```text
FORGETTING-CLOSED
!=
POLY-SIZE FORGETTING
```

q-Horn is the canonical control: forgetting remains expressible in the class, but class closure alone does not prove polynomial output size or a polynomial total lifecycle.

### A3 — Easy pieces can form a hard mixture

```text
TRACTABLE COMPONENTS
!=
TRACTABLE MIXTURE
```

The internal `OR2 + EVEN_XOR3` Schaefer barrier and external mixed Horn/2-CNF controls both enforce this rule.

### A4 — Existence of a good order is not discoverability

```text
GOOD ELIMINATION ORDER EXISTS
!=
GOOD ORDER POLY-DISCOVERABLE
```

DP-simplicial elimination is the canonical control: polynomial elimination is useful when a suitable order is supplied, but general order existence/membership is NP-complete.

### A5 — Compact pp/auxiliary descriptions do not remove semantic choice for free

```text
POLY PP DESCRIPTION / AUXILIARIES
!=
POLY SEMANTIC-CHOICE ELIMINATION
```

Polynomially many existential variables or compact pp definitions do not imply polynomial consistency, projection lifecycle, or zero-choice evaluation.
