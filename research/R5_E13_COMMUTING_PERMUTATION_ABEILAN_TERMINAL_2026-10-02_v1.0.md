## 1. Permutation normal form

Let `A` be a square `0/1` matrix with every row and column sum equal to three.
Its bipartite incidence graph is 3-regular and therefore its edges can be decomposed into three perfect matchings in polynomial time.

After permuting rows/columns so that one matching is the identity, write

```text
A = I + P + Q
```

where `P,Q` are permutation matrices.

The Exact-One equations are

```text
x_i + x_{P(i)} + x_{Q(i)} = 1,
```

and the centered kernel equations are

```text
y_i + y_{P(i)} + y_{Q(i)} = 0,
y in {-1,2}^n.
```

## 2. Commuting hypothesis

Assume

```text
P Q = Q P.
```

The group generated by `P,Q` is abelian.  Decompose the index set into its orbits.  The equations do not couple distinct orbits, so each orbit can be solved independently.

Fix one orbit `O`.  The effective action of the abelian group on a transitive orbit is regular after quotienting by the kernel of the action.  Thus `O` can be identified with a finite abelian group `G` generated by two elements `p,q`, with

```text
P:g -> g+p,
Q:g -> g+q.
```

## 3. Fourier kernel classification

Because `G` is finite abelian, its complex characters form a basis of simultaneous eigenvectors for `P,Q`.
For a character `chi`,

```text
P chi = chi(p) chi,
Q chi = chi(q) chi,
```

so

```text
(I+P+Q) chi
= (1 + chi(p) + chi(q)) chi.
```

Since `chi(p),chi(q)` lie on the unit circle,

```text
1 + chi(p) + chi(q) = 0
```

holds iff the three unit complex numbers are the three cube roots of unity.  Hence, up to interchange,

```text
chi(p) = omega,
chi(q) = omega^2,
```

where `omega^3=1` and `omega!=1`.

Because `p,q` generate the effective group, prescribing `chi(p),chi(q)` determines `chi` uniquely.  Therefore on a transitive commuting orbit:

```text
nullity_C(I+P+Q) is either 0 or 2,
```

where the two zero characters, when they exist, are complex conjugates.  Hence the same real/rational nullity is `0` or `2`.

## 4. Z3 labeling equivalence

A zero character has image in the cube roots of unity.  Write

```text
chi(g) = omega^{c(g)}
```

with `c(g) in Z_3`.

Then, for one of the two orientations,

```text
c(Pv) = c(v) + 1 mod 3,
c(Qv) = c(v) - 1 mod 3.
```

Conversely, any such consistent labeling defines the zero character.

Therefore the following are equivalent on one commuting orbit:

```text
ker(I+P+Q) != 0
<=>
there is a consistent Z3 labeling with increments (+1,-1)
   or (-1,+1).
```

## 5. Constructing the Exact-One witness

Suppose a consistent labeling exists.  For any fixed residue `r in Z3`, define

```text
x_v = 1 iff c(v)=r.
```

For every source row indexed by `v`, the three variables

```text
v, P(v), Q(v)
```

have colors

```text
c(v), c(v)+1, c(v)-1,
```

which are exactly the three residues modulo three.

Hence exactly one has color `r`, and

```text
x_v + x_{P(v)} + x_{Q(v)} = 1.
```

Thus each residue class gives an Exact-One witness.

Conversely, if an Exact-One witness exists, then `y=3x-1` is a nonzero vector in the kernel.  On a commuting orbit the Fourier classification above says the kernel is zero unless the Z3 character exists.  Therefore absence of both orientations is an exact UNSAT certificate for that orbit.

