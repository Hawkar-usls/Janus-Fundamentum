## 1. Three pair-choice bits

For a fixed conflict vertex `v`, its three source rows partition the six neighbors
into three adjacent pairs

```text
P_1={a_1,b_1}, P_2={a_2,b_2}, P_3={a_3,b_3}.
```

Any independent 3-subset of `N(v)` can contain at most one endpoint from each source
pair.  Since a claw leaf set has size three, it contains exactly one endpoint from
every pair.

Choose an arbitrary orientation of every pair and encode a claw by

```text
z=(z_1,z_2,z_3) in {0,1}^3,
```

where `z_i` records which endpoint of `P_i` is selected.

Thus the local claw family is a subset

```text
C_v subseteq {0,1}^3.
```

## 2. Cross edges are 2-CNF forbiddances

Between two distinct source-pairs `P_i,P_j` there are four possible cross edges.
A cross edge joining endpoint value `a` in pair `i` to endpoint value `b` in pair
`j` forbids exactly the pair-choice pattern

```text
z_i=a, z_j=b.
```

Equivalently it contributes one binary clause forbidding that assignment.

There are

```text
3 pair-pairs * 4 endpoint combinations = 12
```

possible cross edges.

Therefore every local claw family is exactly the satisfying set of a 2-CNF formula
on three Boolean variables generated by some subset of these 12 clauses.


```text

```

Call such a claw family coordinate-surjective.

## 5. Cube symmetry quotient

The arbitrary choices used to label source-pairs and orient their two endpoints do
not carry mathematical content.

The natural symmetry group is generated by

```text

independently flipping each coordinate (C_2^3).
```

This group has size `48`.
