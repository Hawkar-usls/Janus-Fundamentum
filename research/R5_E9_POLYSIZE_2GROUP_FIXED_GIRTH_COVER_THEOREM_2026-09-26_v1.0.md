## 1. Theorem

Fix integers

```
Delta >= 2,
g >= 3.
```

There is a constant C=C(Delta,g) and a deterministic polynomial-time
construction with the following property.

For every finite connected graph H on n vertices with maximum degree at most
Delta, one can construct a connected finite cover

```
H_tilde -> H
```

such that

```
cover degree = 2^s <= n^C
```

for some s and

```
girth(H_tilde) >= g.
```

More precisely the cover may be taken as a connected component of a regular
voltage cover whose voltage group is a finite 2-group.

For JANUS we use only

```
Delta=3,
g=10.
```

If H is bipartite / cubic / edge-coloured by the three source perfect
matchings, those properties lift to H_tilde.

## 2. One fixed finite 2-group for all short word patterns

Let F_{g-1} be the free group on

```
x_1,...,x_{g-1}.
```

There are finitely many nontrivial reduced words of length <g in these
generators.  Call this finite set W_g.

Free groups are residually finite 2-groups.  Therefore, for each w in W_g,
there is a finite 2-group K_w and a homomorphism

```
rho_w:F_{g-1}->K_w
```

with rho_w(w) != 1.

Take the finite direct product

```
K_g = product_{w in W_g} K_w.
```

It is one fixed finite 2-group depending only on g.

No word w in W_g is an identity law on K_g: in its own factor K_w there is
an assignment of the free generators on which w evaluates nontrivially.

Put

```
B=|K_g|,
epsilon=B^{-(g-1)},
q=1-epsilon < 1.
```

For any nontrivial reduced word w of length <g involving k<=g-1 distinct
variables, independent uniform K_g values make w nonidentity for at least one
of the B^k assignments.  Hence

```
Pr[w=1] <= 1-B^{-k} <= q.
```

The constants B,epsilon,q depend only on g, never on H or n.

This is the only group-theoretic input, and PA-0027 source-binds it to the
classical residual-2 theorem.

## 3. Only O(n) short closed walks need to be killed

Choose one orientation for every edge of H and give reverse traversal the
inverse voltage.

Let B(H,g) be the collection of rooted nonbacktracking closed walks in H of
length <g.

A crude bound is

```
M:=|B(H,g)|
<=
n Delta sum_{ell=1}^{g-1}(Delta-1)^{ell-1}
=
O_{Delta,g}(n).
```

For the exact JANUS values Delta=3,g=10,

```
M <= 1533 n.
```

Each W in B(H,g) reads a freely reduced nontrivial word in the oriented
edge-voltage variables: nonbacktracking forbids adjacent inverse cancellation.

After renaming its at most g-1 distinct edge variables, this is one of the
patterns covered by Section 2.

## 4. Random product voltage kills all short walks

Choose t independent K_g-valued voltage assignments to all oriented base
edges.

Equivalently, assign voltages in

```
K = K_g^t.
```

For one fixed short walk W,

```
Pr[voltage_K(W)=1]
<=
q^t.
```

Therefore

```
Pr[there exists a bad W with voltage 1]
<=
M q^t.
```

Choose

```
t >
log(M)/(-log q).
```

Then M q^t <1, so some voltage assignment makes every nonbacktracking closed
walk of length <g have nonidentity voltage.

Because M=O(n) and q is a fixed constant,

```
t=O(log n).
```

The deck group has order

```
|K|
=
B^t
=
n^{O_{Delta,g}(1)}.
```

Thus the cover degree is polynomial.

## 5. Girth of the derived cover

Construct the regular voltage cover H_K.

If H_K contained a cycle of length <g, projecting it to H would give a closed
nonbacktracking walk W of the same length.

A cycle cannot project with an immediate edge reversal: by the covering
property the unique lift of the reverse base edge would immediately traverse
the same lifted edge backward.

Since the lifted cycle closes, its projected walk has identity net voltage.

This contradicts the choice in Section 4.

Therefore

```
girth(H_K) >= g.
```

## 6. Connected cover

The derived K-cover need not be connected.

Take any connected component H_tilde.

Because H is connected, each component projects surjectively to H and is a
cover of constant degree equal to the order of the subgroup generated by
closed-walk voltages from one base fibre.

That subgroup is a subgroup of the finite 2-group K, hence has 2-power order
at most |K|.

Every cycle of H_tilde is also a cycle of H_K, so

```
girth(H_tilde)>=g.
```

Thus H_tilde is the required connected polynomial-degree 2-power cover.

## 7. Deterministic polynomial construction

The probabilistic proof can be derandomized.

Work one K_g coordinate at a time.  Suppose R short walks remain un-killed by
the coordinates already chosen.

A fresh random K_g voltage coordinate leaves expected at most

```
qR
```

of them with identity voltage.

Choose the edge voltages greedily by conditional expectation.

For one partially assigned voltage coordinate and one short walk, at most g-1
distinct edge variables of that walk remain unset.  Since g and K_g are fixed,
its exact conditional probability is computable by brute force over at most

```
B^{g-1}
```

constant possibilities.

Hence one full coordinate reducing the survivor count to at most qR is found
in polynomial time.

After O(log n) coordinates no short walk survives.

The fixed group K_g may be hard-coded once for fixed g.  If desired, it can
also be found by a finite offline enumeration of finite 2-groups and generator
assignments; residual-2 guarantees termination.  This preprocessing is
independent of H and n.

## 8. Composition with NM-0029

Take now a connected cubic bipartite JANUS incidence graph and lift its three
edge colours along the cover.

After normalizing the lifted first perfect matching, the resulting
P_tilde,Q_tilde form a labelled cover of P,Q.

If the base satisfies

```
PQ != QP,
phase = FAIL,
d=dim_Q ker(I+P+Q)=omega(log n),
```

then NM-0029 gives for every polynomial-degree 2-group cover:

```
P_tilde Q_tilde != Q_tilde P_tilde,
phase_tilde = FAIL,
d_tilde = omega(log |Omega_tilde|).
```

NM-0030 now additionally supplies

```
incidence girth >=10
```

at polynomial cover degree.

Therefore the high-girth part of the PA-0025 filtered-cover construction no
longer requires a new spectral mode or a superpolynomial cover.

## 9. What remains open

This theorem does NOT preserve a specified base 10-cycle.

The constructed cover may have girth strictly greater than ten.  In that case
there need not be an incidence 10-cycle and therefore NM-0028's exact conflict
C5 sparse-attachment control need not occur.

So the filtered family still requires both:

1. a connected cubic base family with
   `nullity=omega(log n)`, noncommuting P,Q and phase FAIL;
2. either a base / cover theorem guaranteeing some incidence cycle of length
   2 mod 4 (preferably exactly 10) while all shorter cycles are removed, or a
   replacement sparse odd-hole theorem at another surviving cycle length.
