## 1. Affine-F3 cover setting

Let a row-weight-three Exact-One source have a consistent affine system

```text
A r = 1 over F3.
```

Compute

```text
r(alpha)=r0+B alpha,
alpha in F3^d,
col(B)=ker_F3(A).
```

For coordinate `i`, with row `b_i` of `B`, the zero set is

```text
H_i={alpha : b_i alpha = -r0_i}.
```

By AF3-1, the source is Exact-One UNSAT iff the coordinate-zero hyperplanes cover all of `F3^d`.

As in the rank-1 terminal, projectively normalize every nonzero normal. Write the normalized equation as

```text
c_i alpha = t_i,
```

where the first nonzero coordinate of `c_i` is 1.

## 2. Cover-normal rank

For a subfamily `S` of coordinate hyperplanes define its normal rank as

```text
rho(S)=dim_F3 span{c_i : i in S}.
```

A rank-zero cover occurs only when some coordinate is identically zero throughout the affine solution space; this is already an immediate UNSAT terminal.

The parallel-triple theorem is exactly the rank-one case: three parallel hyperplanes with offsets 0,1,2 cover the one-dimensional quotient.

This note solves the entire rank-at-most-two case constructively.

## 3. Quotient-cover theorem

### Theorem R2F3-1

Let `u,v` be linearly independent nonzero normal vectors in `(F3^d)^*`, and put

```text
U=span_F3{u,v}.
```

For every coordinate hyperplane whose normal `c_i` lies in `U`, write uniquely

```text
c_i = a_i u + b_i v,
(a_i,b_i) in F3^2 \ {(0,0)}.
```

Define the induced affine line in `F3^2`

```text
L_i={(x,y): a_i x + b_i y = t_i}.
```

Then

```text
union_{c_i in U} H_i = F3^d
iff
union_{c_i in U} L_i = F3^2.
```

### Proof

The linear map

```text
pi:F3^d -> F3^2,
pi(alpha)=(u alpha, v alpha)
```

is surjective because `u,v` are independent. For `c_i=a_i u+b_i v`,

```text
alpha in H_i
iff a_i(u alpha)+b_i(v alpha)=t_i
iff pi(alpha) in L_i.
```

Thus the union of all such `H_i` is exactly the inverse image under `pi` of the union of the induced lines. Surjectivity proves the equivalence. QED.

The rank-one version is identical with quotient `F3`.

## 4. Polynomial recognition and construction

Any rank-at-most-two covering subfamily has its normal span generated by one or two normals already present among the coordinate hyperplanes. Therefore no hidden basis search is required.

Algorithm:

```text
INPUT: source A.

1. Solve A r=1 over F3.
   inconsistent => UNSAT.
2. Construct r0 and kernel basis B.
3. Handle identically-zero coordinate terminal.
4. Projectively normalize all nonzero coordinate hyperplanes (c_i,t_i).
5. Rank-1 pass:
   group by c_i; if offsets {0,1,2} occur => UNSAT.
6. Rank-2 pass:
   for every pair of distinct projective normals u,v:
      U=span{u,v};
      collect every coordinate hyperplane with c_i in U;
      express c_i=a_i u+b_i v;
      test the 9 points of F3^2 against the induced lines.
      if all 9 points are covered:
          return UNSAT with (u,v) and the covering coordinate indices.
7. Otherwise return NOT_IN_RANK2_COVER_ROUTER.
```

There are at most `n` observed projective normals and at most `O(n^2)` pairs. For each pair, membership/coefficient recovery can be done by constant-field elimination or by testing the nine coefficient pairs, and at most `n` hyperplanes are scanned. The quotient has exactly nine points.

Therefore the construction cost is polynomial; a naive implementation is `O(n^3 d)` field operations up to constant factors.

## 5. Certificate verification

A rank-two UNSAT certificate contains:

```text
basis normals u,v,
a list of source coordinate indices,
and for each listed index the quotient coefficients (a_i,b_i) and offset t_i.
```

A verifier checks:

1. each equation is the actual normalized coordinate-zero equation;
2. `u,v` are independent;
3. each listed normal equals `a_i u+b_i v`;
4. all nine quotient points in `F3^2` satisfy at least one listed line.

This is polynomial and proves that every affine solution has a zero coordinate, hence Exact-One UNSAT by AF3-1.
