## 0. Strategic correction

The previous 6H wording over-weighted novelty as an admission condition.

That is not the research objective.

The objective is:

```text
FIND / SYNTHESIZE / PROVE
A UNIVERSAL UNIFORM POLYNOMIAL SAT ALGORITHM.
```

A mechanism may be:

- old;
- classical;
- rediscovered independently;
- already present elsewhere in JANUS;
- composed from multiple known mechanisms.

Novelty is optional.

What is mandatory is that the **composition closes a previously open obligation without hiding complexity elsewhere**.

Therefore the governing rule becomes:

```text
NOVELTY
=
OPTIONAL

SOURCE BINDING
=
MANDATORY WHEN USING KNOWN MECHANICS

UNIVERSALITY
=
MANDATORY FOR D1

PROOF-CARRYING POLYNOMIAL LIFECYCLE
=
MANDATORY
```

## 1. Corpus-first research model

Treat the JANUS corpus as a theorem/mechanism library.

For every mechanism M, record its role:

```text
M.COVERAGE
M.DISCOVERY
M.REPRESENTATION
M.PROJECTION
M.PRESERVATION
M.CONSISTENCY
M.RECONSTRUCTION
M.VERIFICATION
M.GLOBAL_BUDGET
```

A mechanism is reusable even if previously rejected as a complete solver, provided it is used only for an obligation it actually closes.

Example:

```text
DP / RESOLUTION
may be rejected as a universal flat-CNF route

BUT

a bounded local resolvent identity
may still be a valid local compaction donor.
```

Likewise:

```text
2-SAT
may be insufficient for universal decoder discovery

BUT

may remain a valid discovery engine
for a strict admitted subclass.
```

The corpus must preserve both facts simultaneously.

## 2. Composition theorem requirement

A pipeline assembled from known mechanisms

```text
M1 -> M2 -> ... -> Mk
```

is not admitted merely because every stage is individually polynomial on its own promised inputs.

A composition theorem must prove:

```text
1. exact semantic compatibility at every interface;

2. every stage's precondition is established
   by the previous stage in polynomial time;

3. no stage requires an oracle hidden in
   "recognize", "simplify", "choose", or "compile";

4. all intermediate states/certificates
   have size poly(original L);

5. the number of stage invocations / updates
   is poly(original L);

6. reconstruction and verification
   are poly(original L);

7. aggregate total lifecycle
   is bounded by one fixed polynomial in L.
```

This is the JANUS replacement for a novelty test.

## 4. Rediscovery policy

If a candidate reduces to an existing mechanism, do **not** discard it automatically.

Instead classify:

```text
REDISCOVERY_OF_EXISTING_MECHANISM
=
YES
```

then ask:

```text
DOES THIS USE CLOSE
A NEW GLOBAL OBLIGATION
IN A WAY NOT PREVIOUSLY COMPOSED?
```

If no:

```text
NO NEW GATE.
```

If yes:

```text
OPEN A COMPOSITION GATE,
NOT A NOVELTY GATE.
```
