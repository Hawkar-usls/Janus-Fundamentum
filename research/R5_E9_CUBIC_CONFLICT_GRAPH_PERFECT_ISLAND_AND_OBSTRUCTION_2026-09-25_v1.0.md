## 1. Exact setting

Let the current cubic perfect-kernel instance be

```
A = I + P + Q,
Ax = 1,
x in {0,1}^Omega,
```

where `P,Q` are permutations, every row and column of A has weight three,
and the action generated by P,Q is transitive.

Write `n=|Omega|`.  The cubic incidence count gives n rows and n columns.

Define the variable-conflict graph `C(A)):
two variables are adjacent exactly when they occur together in a row of A.

## 2. Exact stable-set identity

Every independent set X of `C(A)` selects columns of A with pairwise-disjoint
supports.  Every selected column has exactly three ones.  Therefore

```
3|X| <= n,
```

so `alpha(C(A))<=n/3`.

If x is an exact-one witness, its support is independent and the selected
columns cover all n rows exactly once.  Hence its size is n/3.

Conversely, an independent set X of size n/3 selects n pairwise-disjoint row
incidences in total.  Since there are exactly n rows, every row is covered once.

Thus

```
boxed(
  Ax=1 has a Boolean witness
  iff
  alpha(C(A)) = n/3
).
```

The witness reconstruction is the identity map:
vertices of the stable set are the true variables.

A first trivial terminal rule is also explicit:

```
3 does not divide n
->
UNSAT.
```

No semantic oracle is used.

## 3. Conflict degree is at most six

A variable occurs in exactly three clauses.  In each clause it meets at most
two other variables.  Therefore

```
Delta(C(A)) <= 6.
```

Repeated co-occurrence can only lower the degree.

Moreover, transitivity of the group generated by P,Q implies `C(A)` is
connected: each row contains the identity coordinate and the two generator
images (up to the harmless inverse convention), so the undirected generator
edges are contained in the conflict graph.

## 5. Canonical imperfect obstruction

If `C(A)` is not perfect, the Strong Perfect Graph Theorem gives an induced

```
odd hole
or
odd antihole.
```

This is a source-backed structural dichotomy, not a new recognition theorem.

The cubic degree bound sharply restricts the antihole branch.

An induced antihole on l vertices is the complement of an induced cycle C_l.
Every vertex has

```

```

neighbors inside the antihole.  Since `Delta(C(A))<=6`,

```
l-3 <= 6,
```

and therefore

```

```

For odd antiholes allowed by the Strong Perfect Graph Theorem, only

```

```

remain.

Hence:

```

=
```

This is the main new structural sharpening.

## 6. The 9-antihole is an exact terminal obstruction

For l=9, every antihole vertex already has internal degree

```
9-3=6.
```

It therefore has no neighbor outside the antihole.  Since `C(A)` is connected,
an induced 9-antihole forces

```
C(A) ~= complement(C_9).
```

But

```
alpha(complement(C_9)) = 2
<
9/3 = 3.
```

So the instance is UNSAT.

The checker includes an explicit cubic 9-clause / 9-variable incidence system
whose conflict graph is exactly `complement(C_9)`, proving that this terminal
case is realizable rather than vacuous.

## 7. What is NOT solved

The 5- and 7-antihole branches are constant-size local obstructions but may
attach to the rest of the conflict graph.

Odd holes have unbounded length.

Naively replacing each obstruction by an arbitrary boundary truth table is
not accepted: repeated use can merely move the exponential interaction state
into the boundary representation.

Likewise, generic maximum independent set on the imperfect remainder is not
an admissible oracle.

Therefore this artifact does NOT claim a polynomial solver for the full
perfect-kernel residual.
