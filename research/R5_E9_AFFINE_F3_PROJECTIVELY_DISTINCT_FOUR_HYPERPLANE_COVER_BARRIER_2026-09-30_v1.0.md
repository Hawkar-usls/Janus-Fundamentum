# R5 E9 — Affine F3 projectively-distinct four-hyperplane cover barrier

Date: 2026-09-30

Status: `JANUS_EXACT_HYPERPLANE_COVER_BARRIER__NO_D1_PROMOTION`

## 1. Parent gate

The exact source reformulation

\[
A\text{ Exact-One SAT}\iff \exists \alpha\in\mathbb F_3^d\;\forall i:\;r_i^{(0)}+b_i\alpha\ne0
\]

turns UNSAT into coverage of the affine parameter space by the coordinate-zero hyperplanes

\[
H_i=\{\alpha:b_i\alpha=-r_i^{(0)}\}.
\]

A tempting shortcut is to hope that large dimension `d` plus projectively distinct normal directions forces an uncovered point.

This note falsifies that shortcut in the strongest possible dimension-independent way.

## 2. Four hyperplanes cover F3^2

In `F3^2` define

```text
H1: x = 0
H2: y = 0
H3: x-y = 0
H4: x+y = 0
```

Their normal vectors are

```text
(1,0), (0,1), (1,-1), (1,1),
```

which represent the four distinct points of the projective line `PG(1,3)`. Hence no two normals are projectively proportional.

Every nonzero vector `(x,y)` of `F3^2` lies on exactly one of these four one-dimensional linear subspaces, while the origin lies on all four. Therefore

\[
\boxed{H_1\cup H_2\cup H_3\cup H_4=\mathbb F_3^2.}
\]

## 3. Lift to every dimension

For any `d>=2`, pull these equations back through the coordinate projection

\[
\pi:\mathbb F_3^d\to\mathbb F_3^2,
\qquad
\pi(\alpha_1,\ldots,\alpha_d)=(\alpha_1,\alpha_2).
\]

The four resulting hyperplanes in `F3^d` have the same four pairwise nonprojective normal directions and cover every point of `F3^d`.

Thus for every `d>=2`:

\[
\boxed{
\text{four affine/linear hyperplanes with pairwise projectively distinct normals can cover }\mathbb F_3^d.
}
\]

## 4. Consequence for AF3

Therefore none of the following premises can by itself imply an AF3 SAT terminal:

```text
large ternary nullity / large affine dimension,
no repeated normal direction,
no complete parallel class of three affine hyperplanes,
RKPR-style projective distinctness of coordinate functionals.
```

A dimension-growing lower bound on the number of covering hyperplanes is unavailable under only those assumptions.

The source-specific problem must use additional relations among the normals/offsets generated by the cubic incidence matrix, or another global decomposition/augmentation theorem.

## 5. Literature boundary

Jamison and Brouwer--Schrijver type covering/blocking theorems give strong dimension-dependent bounds for different cover models (for example covering all nonzero vectors while avoiding the origin). They do not contradict the present construction, because AF3 UNSAT requires a cover of the entire affine parameter space, where a constant-size projective-pencil cover is possible.

The four-plane construction is elementary and is included explicitly so no external theorem is required for the barrier.
