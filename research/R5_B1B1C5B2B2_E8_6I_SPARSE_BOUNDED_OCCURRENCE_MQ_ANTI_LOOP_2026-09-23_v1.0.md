# R5 E8 6I — Sparse / Bounded-Occurrence MQ Anti-Loop\n\nDate: 2026-09-23\n\nAuthority: SOURCE_BOUND_DERIVED_HARDNESS_CONTROL__NOT_A_P_NE_NP_CLAIM\n\n## 1. Source restriction\n\nCraig Tovey, A simplified NP-complete satisfiability problem, Discrete Applied Mathematics 8 (1984), proves that 3-SAT remains NP-complete when every variable appears in at most four clauses.\n\n## 2. JANUS reduction under this restriction\n\nApply the already proved three-sheet quadratic normal form only to 3SAT-4 inputs.\n\nFor each clause:\n\n- introduce only two local flip variables u,v;\n- add uv=0;\n- add one expanded majority quadratic equation containing eight quadratic monomials.\n\nOccurrence copies of an original Boolean variable are linked only by a linear repetition-code chain. Since each original variable has at most four clause occurrences, this chain has constant length.\n\nTherefore, in the quadratic pre-lift Q(F):\n\n- every quadratic equation has constant support;\n- every flip variable occurs only inside one clause gadget;\n- every occurrence variable participates in one clause gadget plus at most two linear equality equations;\n- the nonlinear interaction degree is bounded by a constant;\n- the total number of variables, equations, and quadratic monomials is linear in the input length.\n\n## 3. Consequence\n\nThe restriction of the JANUS sparse F2 quadratic family obtained from 3SAT-4 is already NP-hard under a polynomial, in fact linear-size, reduction.\n\nHence neither of the following is a valid standalone tractability theorem:\n\n    sparse MQ => polynomial\n    bounded variable occurrence / bounded nonlinear degree => polynomial\n\nunless it uses additional structure strong enough to handle an NP-hard source family.\n\nThis is a scoped hardness control, not an impossibility proof for a new algorithm and not a claim that P differs from NP.\n\n## 4. What remains potentially useful\n\nSparsity may still become useful when combined with a stronger invariant such as:\n\n- bounded treewidth or branchwidth;\n- a matroidal / delta-matroidal composition law;\n- an acyclicity notion preserved by the generated family;\n- a polynomial quotient or cycle-space certificate;\n- a recursive cut language with a separately proved exact polynomial solver.\n\nBut the stronger property must be proved for every generated instance. Bounded degree alone is insufficient.\n\n## 5.
