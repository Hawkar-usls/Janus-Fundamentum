## 1. Faithful cographic normal representation

Let H=(V,E) be a connected graph.

Let C(H) be its binary cycle space and let

```text
W = C(H)^*
```

be the dual normal space.

For every edge e, let g_e in W be the coordinate functional restricted to
C(H).

At every graph vertex v,

```text
sum_{e incident v} g_e = 0,
```

because every binary cycle has even degree at v.

For a cubic H, each distinguished Tanner/normal check is therefore one rank-2
line spanned by the three incident edge normals.

## 2. Vertex-side normal spans

Take a nonempty proper vertex set S and write T=V-S.

Define

```text
W_S = span of g_e for edges with at least one endpoint in S,
W_T = span of g_e for edges with at least one endpoint in T.
```

The crossing set is

```text
delta(S).
```

Every crossing edge normal lies in both W_S and W_T, so

```text
span(delta(S)) subseteq W_S intersect W_T.
```

The key point is that equality holds in the faithful cographic representation.

## 3. Why the intersection contains nothing else

Represent W as the quotient

```text
GF(2)^E / Cut(H),
```

where Cut(H) is the binary cut space generated by the vertex stars.

Suppose x lies in W_S intersect W_T.

Choose edge-space representatives

```text
a supported on edges incident to S,
b supported on edges incident to T
```

for the same quotient vector x.

Then

```text
a+b
```

lies in Cut(H), so it equals a graph cut vector delta(R).

Let R_S=R intersect S.

Subtract the cut delta(R_S) from a.  This does not change the quotient class,
and it cancels every S-internal edge of a.

The resulting representative is supported only on delta(S).

Therefore

```text
boxed:
W_S intersect W_T = span{g_e : e in delta(S)}.
```

So the subspace-arrangement cut width is exactly the rank of the crossing-edge
normals.

## 4. Nontrivial 3-edge cuts

Now assume

```text
|delta(S)|=3
```

and both sides contain more than one vertex.

Summing all vertex-star relations over S cancels every internal edge twice and
leaves

```text
g_e1+g_e2+g_e3=0
```

for the three cut edges.

In a 3-edge-connected faithful cographic graph, none of these normals is zero
and no two are parallel.  Hence

```text
rank{g_e1,g_e2,g_e3}=2.
```

Combining with Section 3 gives

```text
boxed:
dim(W_S intersect W_T)=2.
```

Thus every nontrivial cographic 3-edge cut is an exact width-2 separator of the
distinguished-check normal arrangement.

## 5. Constructive detection

No deep graph algorithm is needed for the theorem.

For a cubic graph with O(n) edges, enumerate all edge triples and test whether
their deletion disconnects the graph.

This is polynomial.

So every nontrivial 3-edge-cut escape from E115 is algorithmically visible.
