# C023R — Exact execution-DAG path multiplicity theorem

Authority: `EXACT_COMBINATORIAL_LEMMA__NO_SCIENTIFIC_PROMOTION`  
Method: `STRICT_ALGEBRA_COMBINATORICS__NO_HEURISTICS`

## Why this object

Historical Policy-0A descendant keys may contain inherited local-Resolution clauses, so source-factor provenance is not recoverable from key syntax without another theorem. Cache multiplicity itself, however, has a provenance-free exact graph interpretation.

## Definition — labeled unique-key execution DAG

For one fixed frozen unsatisfiable input, construct a directed multigraph `D`:

- one vertex for every unique nonterminal canonical cache key/state created by Policy-0A;
- root is the first state;
- for every recursive branch child that reaches a nonterminal key `K'`, add one directed edge from the parent state to the state with key `K'`;
- preserve branch-value labels, so two branch values from one parent that reach the same key are two distinct directed edges;
- cache hits point to the already completed state with that byte-identical key;
- terminal direct conflicts with no cache key are not vertices.

Because each recursive call adds one new decision variable and assigned variables are never reintroduced, the state transition relation is acyclic along execution depth.

## Lemma D1 — occurrence/path bijection

Let `T` be the full unfolding obtained by replacing every cache edge by a fresh copy of the referenced completed subexecution.

For every state vertex `v` of `D`, occurrences of `v` in `T` are in bijection with directed labeled root-to-`v` paths in `D`.

Proof by induction on depth:

- root has one occurrence and one empty path;
- every occurrence of a child is generated by exactly one parent occurrence plus one labeled branch edge;
- unfolding a cache edge creates exactly the occurrence represented by extending that root-to-parent path with the cache edge;
- conversely every directed labeled path specifies exactly one recursive occurrence in the unfolding.

Therefore

`m(v) = number_of_directed_labeled_paths(root,v)`.

This identity uses no source provenance, Resolution simulation, or semantic quotient.

## Definition — merge surplus

For the ancestor sub-multigraph `A_v` induced by all vertices and edges lying on at least one root-to-`v` path, choose one canonical incoming edge for every non-root vertex. Call all remaining incoming edges `merge edges`.

Define

`mu(v) = sum_{u != root in A_v} (indeg_Av(u)-1)`.

Equivalently, because `A_v` is rooted and every non-root vertex has indegree at least one,

`mu(v) = |E(A_v)| - |V(A_v)| + 1`.

The value is independent of which incoming edges are chosen as canonical.

## Lemma D2 — path-count upper bound

For every state `v`,

`m(v) <= 2^{mu(v)}`.

Proof. Remove all merge edges. Every non-root vertex then has exactly one canonical incoming edge, so there is at most one canonical predecessor chain from root to any vertex.

For a directed root-to-`v` path in the original graph, record the subset of merge edges used by that path. Given `v` and that subset, reconstruct the path backwards uniquely: at the current vertex use its selected merge incoming edge if the subset contains one; otherwise use the canonical incoming edge. A valid path cannot use two distinct incoming edges of one vertex. Hence different paths have different merge-edge subsets. There are at most `2^{mu(v)}` subsets. QED.

## Global identity — cache hits are indegree excess

For the whole reachable unique-state DAG `D`, every first arrival to a non-root state supplies its canonical incoming edge. Every later recursive arrival at an already completed byte-identical state is exactly a cache-hit edge and contributes one unit of indegree excess.

Therefore, when dependency edges count exactly the recursive state-to-state transitions,

`total_cache_hit_edges = |E(D)| - |V(D)| + 1 = mu_total`.

The frozen revealed MAJ3-K4 diagnostic independently replays this identity:

- unique states `|V| = 2427`;
- dependency edges `|E| = 3314`;
- exact cache hits `= 888`;
- `3314 - 2427 + 1 = 888`.

This finite equality is a replay of the general combinatorial identity, not asymptotic evidence.

## Corollary — sufficient PASS condition for the cache-fiber bridge

If one proves for the frozen q=4 Morgenstern family that

`max_v mu(v) = o(L_t)`,

then for every state

`log2 m(v) <= mu(v) = o(L_t)`,

so the required subexponential cache-fiber condition follows.

This is sufficient, not necessary: `mu(v)` can be large while path compatibility keeps `m(v)` smaller.

## Definition — serial diamond packing

A serial diamond is a pair of distinct directed labeled paths from one state `a` to a later state `b` with no common internal vertices, representing two distinct execution histories that merge at the same byte-identical key.

A sequence of `k` serial diamonds is compatible when every choice of one arm from each diamond concatenates to a valid root-to-target path and the diamonds occur in a fixed topological order.

## Lemma D3 — decisive FAIL certificate

If, for infinitely many family members, there exists a reachable target state with a compatible packing of `k_t` serial diamonds, then

`m(target) >= 2^{k_t}`.

Hence a proof that

`k_t >= c L_t`

for one constant `c>0` gives

`m(target) >= 2^{cL_t}`

and decisively falsifies the C023R subexponential cache-fiber transfer route.

## Revised exact target

The current theorem problem can be attacked without first solving source-provenance recovery:

### PASS route
Prove `max_v mu(v)=o(L_t)`, or prove a stronger direct root-to-node path-count bound `m(v)<=2^{o(L_t)}` from frozen transition semantics.

### FAIL route
Construct `Omega(L_t)` compatible serial merge diamonds in the exact historical unique-key transition DAG.

MAJ3 `01/10` restriction equality and Tseitin cycle-space relations are candidate *causes* of diamonds, but they count only after byte-identical historical keys are proved. Semantic equality alone is insufficient because inherited deterministic local Resolution is part of the transition.
