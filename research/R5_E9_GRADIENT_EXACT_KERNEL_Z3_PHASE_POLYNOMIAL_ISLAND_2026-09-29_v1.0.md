# R5 E9 — Gradient-exact kernel gives an exact Z3-phase polynomial island

Date: 2026-09-29
Status: THEOREM / POLYNOMIAL ISLAND
Authority: non-global; `P_VS_NP = OPEN`

## Theorem

Let `A` be a square cubic Exact-One source whose columns are oriented edges of a graph `G=(V,E)` and whose source rows are directed cycles, so that the oriented vertex coboundary map

\[
(Dz)_{u\to v}=z_v-z_u
\]

satisfies

\[
A D=0.
\]

Assume moreover that the entire rational kernel is generated by these gradients:

\[
\boxed{\ker_{\mathbb Q}A=\operatorname{im}_{\mathbb Q}D.}
\]

Then Exact-One satisfiability is equivalent to a linear phase system over \(\mathbb F_3\):

\[
\boxed{
Ax=\mathbf1,\ x\in\{0,1\}^{E}
\iff
\exists\phi:V\to\mathbb F_3\ \forall(u\to v)\in E:\ 
\phi(v)-\phi(u)=-1.
}
\]

Therefore this branch is decidable, constructible, reconstructible, and verifiable in polynomial time by linear consistency/propagation over \(\mathbb F_3\).

---

## Proof: Exact-One implies phase

Suppose

\[
Ax=\mathbf1,\qquad x\in\{0,1\}^{E}.
\]

Because every source row has weight 3,

\[
A\mathbf1=3\mathbf1.
\]

Define

\[
y=3x-\mathbf1.
\]

Then

\[
Ay=3Ax-A\mathbf1=0,
\]

so \(y\in\ker_{\mathbb Q}A\). By the gradient-exact hypothesis there is a rational vertex potential \(z\) such that

\[
y=Dz.
\]

For each oriented edge \(u\to v\),

\[
z_v-z_u=y_{u\to v}\in\{-1,2\}\subset\mathbb Z.
\]

Thus every edge difference is integral. On each connected component choose a root \(r\) and subtract \(z_r\) from all vertex potentials in that component. Along any root-to-vertex path, the resulting potential is a sum of integral edge differences, hence is itself an integer. Therefore there is an integer potential \(z'\) with

\[
y=Dz'.
\]

Reducing this integer potential modulo 3 gives an \(\mathbb F_3\) vertex labelling \(\phi\) satisfying

\[
\phi(v)-\phi(u)=-1
\]

on every oriented edge.

---

## Proof: phase implies Exact-One

Conversely suppose

\[
\phi(v)-\phi(u)=-1\in\mathbb F_3
\]

on every oriented edge.

Choose the standard integer representatives

\[
r_v\in\{0,1,2\}
\]

of \(\phi(v)\).

For each edge \(u\to v\), the integer difference \(r_v-r_u\) lies in \([-2,2]\) and is congruent to \(-1\pmod3\). The only possibilities are therefore

\[
r_v-r_u\in\{-1,2\}.
\]

Set

\[
y=Dr,
\qquad
x=\frac{y+\mathbf1}{3}.
\]

Then every coordinate of \(x\) is 0 or 1. Also \(AD=0\), hence

\[
Ax=\frac{ADr+A\mathbf1}{3}
=\frac{0+3\mathbf1}{3}
=\mathbf1.
\]

So \(x\) is an Exact-One witness.

This direction does not need the kernel-equality hypothesis; `AD=0` and the phase solution are sufficient.

---

## Algorithm

1. Verify the declared oriented-edge / directed-cycle representation and `AD=0`.
2. Verify the gradient-exact condition, equivalently

   \[
   \nu_{\mathbb Q}(A)=\operatorname{rank}_{\mathbb Q}(D).
   \]

   For a connected underlying graph this is \(\nu_{\mathbb Q}(A)=|V|-1\).
3. Solve the edge-difference system over \(\mathbb F_3\)

   \[
   D\phi=-\mathbf1.
   \]

   This can be done by Gaussian elimination or, more directly, by component propagation because every edge fixes a unique relative phase.
4. If inconsistent, return UNSAT.
5. If consistent, choose representatives `0,1,2`, construct

   \[
   x=(Dr+\mathbf1)/3,
   \]

   and verify `x in {0,1}^E` and `Ax=1`.

All arithmetic and verification are polynomial in the source size and bit length.

## Paley(11) control

For the Paley free-orbit source at `p=11`, the exact checker proves

\[
\operatorname{rank}_{\mathbb Q}(A)=45,
\qquad
\nu_{\mathbb Q}(A)=10,
\qquad
\operatorname{rank}_{\mathbb Q}(D)=10.
\]

Hence

\[
\ker A=\operatorname{im}D.
\]

The phase equations are inconsistent, so the source is certified UNSAT in polynomial time.

The earlier potential-diameter argument remains a valid independent UNSAT certificate, but the phase criterion is the algorithmically cleaner terminal.

## Scientific consequence

This result does **not** rescue the nullity-enumeration route: the infinite Paley free-orbit family can have a nonzero quotient

\[
\ker A/\operatorname{im}D
\]

and rational nullity at least \(\Omega(\sqrt n)\).

It does establish a genuine polynomial island:

```text
cycle-incidence source
+ ker_Q(A) = im_Q(D)
=> Exact-One iff Z3 phase
=> deterministic polynomial decision and witness reconstruction
```

The live hard branch is therefore sharpened to

\[
\boxed{\ker A/\operatorname{im}D\ne0.}
\]

The next universal target is to understand whether this quotient admits an exact polynomial representation/reconstruction rule without enumerating its dimension.
