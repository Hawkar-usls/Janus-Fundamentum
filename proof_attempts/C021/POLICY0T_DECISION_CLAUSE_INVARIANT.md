# C021 proof attempt — Policy-0T decision-clause invariant

## Status

`FORMALIZING / RECURSIVE INVARIANT IDENTIFIED / UNIT-REASON LIFTING OPEN`

## Target

For every UNSAT node `u` in a no-cache Policy-0T execution, let

```text
Delta_u
```

be the explicit branch decisions on the root-to-`u` path. Define the decision
clause

```text
B(Delta_u) = OR of the literals falsified by Delta_u.
```

Examples:

```text
x=0 contributes  x
x=1 contributes -x
```

The candidate invariant is:

> From the root axioms and all locally provenance-certified Resolution lines,
> derive a clause `C_u` such that `C_u` is a subclause of `B(Delta_u)`.

The path assignment falsifies every literal of `C_u`. At the root,
`B(Delta_root)` is empty, so the only possible returned subclause is the empty
clause.

## Why a subclause invariant matters

A first proof plan tried to lift every residual proof to the full clause
`B(Delta_u)`. That silently requires weakening. The subclause invariant avoids
this.

Suppose node `u` branches on `x`.

The false child has decisions `Delta_u plus x=0`, hence returns

```text
C_0 subseteq B(Delta_u) union {x}.
```

The true child returns

```text
C_1 subseteq B(Delta_u) union {-x}.
```

There are three cases.

### Both child clauses contain the branch literal

```text
x in C_0
-x in C_1
```

Resolve on `x`. The resolvent is a subclause of `B(Delta_u)`.

### The false-child clause omits `x`

Then

```text
C_0 subseteq B(Delta_u)
```

already certifies the parent conflict. The true child need not be combined into
this returned clause.

### The true-child clause omits `-x`

Symmetrically, `C_1` already certifies the parent.

Thus the branch rule needs no semantic weakening and adds at most one Resolution
layer.

## Finite C021 fixture

The verified trace branches on `x4`.

```text
false child: x4=0 -> returned conflict clause (4)
true child:  x4=1 -> returned conflict clause (-4)
```

Both clauses contain their branch literals, so one Resolution inference yields
`EMPTY` at the root.

This is exactly the first case of the recursive invariant.

## Terminal-node obligation

At a terminal UNSAT node, Policy-0T may detect conflict through:

1. an explicit empty clause after restriction;
2. opposite unit assignments;
3. an empty clause generated by the local Resolution pass;
4. post-resolution unit propagation.

The translator must derive a conflict clause containing only decision literals.
Implied unit literals must be eliminated by resolving the conflict backwards
through their recorded reason clauses.

Required terminal lemma:

> Given an acyclic unit-reason graph ending in conflict and provenance for every
> local learned clause, reverse reason resolution derives a clause contained in
> the current decision clause.

This is the first remaining unproved lemma.

## Residual-clause provenance obligation

A residual clause is obtained from a root or learned clause by deleting literals
falsified by the current assignments. The translator may not treat that deletion
as a legal proof inference.

Instead every residual clause record must retain:

```text
source proof line
removed decision literals
removed implied literals
current restricted clause
```

When the clause participates in a local inference, the translator must either:

- reconstruct the inference at root level while carrying only actually present
  decision literals; or
- defer restriction and eliminate implied literals through their reason clauses.

No full-clause weakening may be hidden in this step.

## Candidate size accounting

Let `W` charge:

```text
all recursive node occurrences
all local Resolution additions
all unit-reason edges
all branch edges
all emitted proof lines
```

Because Policy-0T has no memoization, every execution occurrence has exactly one
place in the search tree. If every local event emits constant proof overhead,
then

```text
proof size = O(W).
```

The proof must not count only unique residual formulas.

## Candidate depth accounting

Along any root-to-leaf path:

- every branch fixes a fresh variable;
- every propagated unit fixes another fresh variable;
- total branch plus unit assignments are at most `N`;
- every local one-pass Resolution stage adds at most one provenance layer;
- every branch combination adds at most one layer.

The intended recurrence is therefore

```text
D(u) <= max(D(child_0), D(child_1)) + O(local assignment events + 1)
```

and telescopes to

```text
D(root) = O(N).
```

This estimate still depends on the terminal unit-reason lemma and a precise rule
for restricted learned clauses.

## Falsification attacks

The invariant is destroyed if any of the following occurs:

1. a terminal conflict requires a clause containing an implied literal that
   cannot be eliminated by recorded reasons;
2. a restricted learned clause cannot be lifted without weakening or
   superconstant hidden work;
3. a branch node has two child conflict clauses but neither can be resolved or
   returned as a parent subclause;
4. one execution event requires superconstant proof overhead after all
   provenance is exposed;
5. proof depth accumulates more than linearly in the total fresh assignments on
   a path.

## Claim boundary

The decision-clause invariant is a proof plan, not a proved theorem. The finite
C021 fixture verifies only one depth-one instance. Until the terminal and
restricted-clause lemmas are formalized and independently checked, H130 and its
MAJ3 asymptotic consequence remain open.
